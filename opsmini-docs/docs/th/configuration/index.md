# คู่มือการกำหนดค่า

-   :material-file-cog-outline: **[ไฟล์กำหนดค่าหลัก](config-file.md)**

-   :material-tune-variant: **[การตั้งค่าพาเนล](panel-settings.md)**

    ---

    Nginx / Caddy Reverse Proxy การอัปเกรด WebSocket เทอร์มินัล

-   :material-lock-outline: **[HTTPS และใบรับรอง](https.md)**
