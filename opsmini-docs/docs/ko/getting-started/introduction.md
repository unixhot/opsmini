# 제품 소개

OpsMini는 경량 Linux 호스트 운영 패널로（바오타 / 1Panel에 대응）, 내장 AI 대형 모델 운영과 대외 표준 REST API를 핵심 차별화 요소로 삼습니다.

## 포지셔닝

| 차원 | 설명 |
|------|------|
| 대상 시나리오 | 단일 Linux 서버（1C1G 소형 호스트도 실행 가능） |
| 핵심 이념 | 한 대 설치하고 한 대 관리, 경량, 단일 머신 우선, 통합 가능 |
| 차별화 | AI 대형 모델 운영 + 표준 REST API |

## 핵심 기능

- **AI 대형 모델 운영**: 자연어로 장애 진단, 로그 분석, 운영 명령 실행, OpenAI / DeepSeek / Qwen / Ollama 연동
- **표준 REST API**: `/api/v1`（브라우저 UI）과 `/agent/v1`（머신 간）, 모니터링 플랫폼, 자동화 스크립트, 오케스트레이션 도구 통합 지원
- **Docker 관리**: 컨테이너, 이미지, 볼륨, 네트워크 네 가지 리소스
- **웹 터미널**: WebSocket + pty로 구현한 SSH 유사 인터랙티브 터미널
- **호스트 보안**: 베이스라인 검사, 파일 무결성 모니터링（FIM）, 위협 탐지, 방화벽, 로그인 보안
- **7개 언어 i18n**: 간체/번체 중국어, 영어, 일본어, 한국어, 태국어, 독일어
- **단일 바이너리 제공**: 프런트엔드를 `go:embed`로 임베드, 런타임 의존성 제로

## 기술 스택

Go 1.25 · Gin · GORM · SQLite（순수 Go）· Vue 3 · ECharts

## 동종 제품과의 차이

| 능력 | 바오타 / 1Panel | OpsMini |
|------|--------------|---------|
| 운영 방식 | 그래픽 수동 조작 | 그래픽 + AI 자연어 운영 |
| 대외 통합 | 표준 API 없음 | 표준 REST API（`/agent/v1`） |
| 모니터링 통합 | node_exporter 추가 설치 필요 | `/metrics` 내장（node_exporter 호환） |
| 제공 형태 | 설치 스크립트 + 다중 컴포넌트 | 단일 바이너리 정적 링크 |
