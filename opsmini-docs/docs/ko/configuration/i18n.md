# 패널 다국어

OpsMini 패널은 7개 언어 인터페이스를 내장하고 있어 추가 설정 없이 전환할 수 있습니다.

## 지원 언어

| 언어 | 코드 |
|------|------|
| 简体中文 | zh |
| 繁體中文 | zh-TW |
| English | en |
| 日本語 | ja |
| 한국어 | ko |
| ไทย | th |
| Deutsch | de |

## 전환 방법

1. 패널 로그인 후 상단 바 우측의 언어 선택기를 클릭합니다
2. 대상 언어를 선택하면 인터페이스가 즉시 전환됩니다

> 언어 기본 설정은 현재 세션에만 적용되며 다른 사용자에게는 영향을 주지 않습니다.

## 구현 설명

- 프런트엔드 언어 팩은 Vue 3 SPA에 인라인되어 있으며, `/api/v1/i18n/{lang}`으로 필요 시 가져올 수도 있습니다
- 7개 언어가 모두 단일 바이너리에 내장되어 있어 별도 다운로드가 없습니다
