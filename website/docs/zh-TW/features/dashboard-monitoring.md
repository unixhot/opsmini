# 儀表盤與監控

OpsMini 內建指標採集與監控告警能力，無需額外安裝監控元件。

## 儀表盤

登入後預設進入儀表盤，展示：

- **資源概覽**：CPU 使用率、記憶體佔用、負載、磁碟、網路流量
- **實時時序**：CPU / 記憶體 / 磁碟 / 網路隨時間變化曲線（ECharts 渲染）
- **系統狀態**：執行時長、主機資訊

指標採集器每 10 秒取樣，記憶體環形緩衝保留 24 小時，歷史資料降取樣後落 SQLite（1 分鐘粒度保留 7 天）。

## 監控

監控頁提供：

- **時序查詢**：按時間範圍檢視歷史指標
- **告警規則**：自定義 CPU / 記憶體 / 磁碟 / 服務等指標的告警閾值與持續時間
- **告警事件**：檢視已觸發的告警事件與狀態

### 告警規則示例

| 欄位 | 說明 |
|------|------|
| 名稱 | 規則名，如「CPU 持續過高」 |
| 指標 | `cpu` / `mem` / `disk` / `service` |
| 條件 | 如 `>90%` |
| 持續時長 | 觸發前需持續滿足的時間 |
| 通知方式 | 關聯的通知渠道 |

## 通知

告警觸發後可透過通知中心推送到管理員，支援站內通知與已讀管理。

## Prometheus 整合

面板內建 node_exporter 相容的 `/metrics` 端點，Prometheus 可直接 scrape，詳見 [Prometheus 指標../api/prometheus.md。
