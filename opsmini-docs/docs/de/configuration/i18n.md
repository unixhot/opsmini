# Panel-Mehrsprachigkeit

Das OpsMini-Panel enthält Oberflächen in 7 Sprachen, die ohne zusätzliche Konfiguration umgeschaltet werden können.

## Unterstützte Sprachen

| Sprache | Code |
|------|------|
| 简体中文 | zh |
| 繁體中文 | zh-TW |
| English | en |
| 日本語 | ja |
| 한국어 | ko |
| ไทย | th |
| Deutsch | de |

## Umschalten

1. Nach der Anmeldung am Panel auf die Sprachauswahl rechts in der oberen Leiste klicken
2. Die Zielsprache auswählen — die Oberfläche wechselt sofort

> Die Spracheinstellung gilt nur für die aktuelle Sitzung und wirkt sich nicht auf andere Benutzer aus.

## Hinweise zur Implementierung

- Das Sprachpaket des Frontends ist in die Vue-3-SPA eingebettet; `/api/v1/i18n/{lang}` kann es bei Bedarf ebenfalls abrufen
- Alle 7 Sprachen sind im einzelnen Binary enthalten, kein zusätzlicher Download
