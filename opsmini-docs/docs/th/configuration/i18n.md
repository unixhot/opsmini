# หลายภาษาของพาเนล

OpsMini พาเนลมีอินเทอร์เฟซ 7 ภาษาในตัว สลับได้โดยไม่ต้องกำหนดค่าเพิ่มเติม

## ภาษาที่รองรับ

| ภาษา | รหัส |
|------|------|
| 简体中文 | zh |
| 繁體中文 | zh-TW |
| English | en |
| 日本語 | ja |
| 한국어 | ko |
| ไทย | th |
| Deutsch | de |

## วิธีสลับ

1. หลังล็อกอินเข้าพาเนล คลิกตัวเลือกภาษาที่มุมขวาบนของแถบบน
2. เลือกภาษาที่ต้องการ อินเทอร์เฟซจะสลับทันที

> ค่ากำหนดภาษามีผลเฉพาะเซสชันปัจจุบัน ไม่กระทบผู้ใช้อื่น

## หมายเหตุการใช้งาน

- แพ็กภาษา frontend ฝังอยู่ใน Vue 3 SPA `/api/v1/i18n/{lang}` ก็สามารถดึงได้ตามต้องการ
- ทั้ง 7 ภาษาอยู่ในไบนารีเดียว ไม่มีการดาวน์โหลดเพิ่มเติม
