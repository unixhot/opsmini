# 앱 관리

앱 관리는 웹사이트, 데이터베이스, 컨테이너, 앱 스토어 네 가지 리소스를 통합적으로 담당합니다.

## 웹사이트

- Nginx 사이트와 정적 사이트 생성 / 관리
- 도메인, 실행 환경（PHP / Node / 정적）, SSL 인증서 발급 및 갱신 설정
- 사이트 시작/중지 및 상태 조회

## 데이터베이스

- MySQL, PostgreSQL 데이터베이스 인스턴스 생성 / 관리
- 데이터베이스 목록, 문자 집합 등 설정 조회

## 컨테이너（Docker）

- **컨테이너**: 목록, 시작, 중지, 재시작, 삭제
- **이미지**: 이미지 조회와 삭제
- **볼륨**: 볼륨 조회와 삭제
- **네트워크**: 네트워크 조회와 삭제

> Docker 관리는 호스트 머신에 Docker가 설치되어 있고 `DOCKER_HOST`가 설정되어 있어야 합니다; Docker 클라이언트 초기화에 실패하면 패널은 우아하게 성능 저하되며 컨테이너 라우트를 숨깁니다.

## 앱 스토어

- 일반적인 앱 분류 내장（웹 서비스, 데이터베이스, 캐시, 모니터링 등）
- 앱 원클릭 설치 / 제거 / 시작 / 중지 / 재시작（Docker Shell 스크립트）
- 사용자 지정 앱 템플릿 가져오기와 공식 템플릿 동기화 지원
