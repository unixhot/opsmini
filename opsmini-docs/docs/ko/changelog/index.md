# 변경 로그

각 버전의 변경 기록.

## v1.1.0（2026-09-21）

**다중 호스트 관리（Agent / Server 아키텍처）**

- **Agent gRPC 클라이언트**: Agent가 OpsMini Server에 능동적으로 연결（단일 포트 gRPC 양방향 스트림）, 하트비트 + 지수 백오프 재연결, 실행 / 파일 작업 수신 및 결과 회신
- **OpsMini Server 측**: 등록 / 하트비트 / 연결 관리, 실행 작업 하달, 결과 수신（코드는 OpsAnt 프로젝트의 독립 Go 서브 프로젝트 `opsmini-server/`로 이전, OpsMini는 Agent만 유지）
- **명령 / 스크립트 실행**: command 및 셸 / python 스크립트, 결과（stdout / stderr / exit code / 소요 시간）회신
- **파일 가져오기（PullFile）**: Server가 Agent로부터 파일을 가져옴（청크 업로드 + size / md5 검증）
- **파일 배포（PushFile）**: Server가 Agent에게 파일을 배포（청크 + 이어받기 재개 + md5 검증）, 대상이 디렉터리인 경우 지원（원본 파일명 유지）
- **연결 상태 감지 + 장기 연결 유지**: Agent 온라인 / 오프라인 상태, 하트비트 타임아웃 판정, gRPC keepalive
- **OpsAnt 연동**: 패널 '설정' 페이지에서 OpsAnt 주소 / Token 시각적으로 구성（런타임 핫 스위칭, Token 표시는 눈 아이콘으로 평문 / 암호 전환 지원）, SSO 인증 없는 리다이렉트（기본 활성화）
- **`/agent/v1` REST API 제거**: gRPC 양방향 스트림으로 변경（기존 REST API 및 프론트엔드 'API Token' 설정 페이지도 함께 제거）

**패널 기능 강화**

- **파일 페이지 디렉터리 다운로드**: 디렉터리를 원클릭으로 zip 압축 다운로드（팝업 안내 + 디렉터리 크기 + 해당 파티션 디스크 사용률）
- **파일 페이지 디렉터리 삭제**: 디렉터리 재귀 삭제（위험 작업 팝업 + 디렉터리명 입력 2차 확인）
- **파일 페이지 긴 이름 최적화**: 매우 긴 파일 / 디렉터리명은 생략 표시, 마우스 오버 시 전체 이름 확인（가로 스크롤바 제거）
- **시스템 관리 '네트워크' 라우팅 테이블**: NIC 아래에 라우팅 테이블 추가 표시（대상 네트워크 / 게이트웨이 / 서브넷 마스크 / 플래그 / 인터페이스 / 메트릭）
- **MCP 구성 강화**: '구성 파일（JSON）'과 '테이블' 두 가지 입력 방식 지원；SSE / HTTP 방식은 사용자 정의 요청 헤더（여러 개）와 타임아웃 지원
- **방화벽 강화**: 활성화 전 패널 포트와 SSH 포트（22）를 자동 허용하여 활성화 후 접근 불가 방지；'설치되었으나 활성화되지 않은' ufw 식별
- **Prometheus 지표 강화**: `opsmini_cpu_usage_percent` / `opsmini_mem_usage_percent` 실시간 사용률, `node_procs_total` 총 프로세스 수 추가
- **확인 팝업 통일**: 모든 삭제 / 위험 작업을 플랫폼 자체 확인 팝업으로 변경（브라우저 네이티브 confirm 대체）

**터미널 최적화**

- **출력 여백**: 명령 출력 좌우 / 하단에 여백 추가, 더 이상 테두리에 붙지 않음
- **전체 화면 Esc 수정**: 전체 화면 모드에서 Esc를 눌러도 전체 화면이 종료되지 않음（vim 편집 모드의 Esc와 충돌 방지）
- **세션 유지**: 페이지 전환 후 터미널 세션이 재설정되지 않음（세션 유효 기간 내 유지）
- **문자 인코딩 설정**: 문자 집합 선택 추가（UTF-8 / GBK / GB18030 / Big5）, 중국어 깨짐 현상 해결

**사용성 최적화**

- **페이지 제목**: 'OpsMini · 접속 주소' 표시, 여러 탭 구분 가능
- **비밀번호 표시 여부**: 비밀번호 변경, OpsAnt Token 연동 등 입력란에 '표시 / 숨기기' 눈 아이콘 추가
- **설정 페이지 레이아웃**: '이중 인증'과 'OpsAnt 연동'을 나란히 표시, '자동 업데이트' 스위치 제거

## v1.0.0（2026-09-13）

OpsMini의 첫 공식 버전, 단일 바이너리 제공, 핵심 기능:

- **AI 운영**: 자연어 진단, 로그 지능형 분석, 명령 생성 및 실행（SSE 스트리밍 출력）, MCP 도구 연동
- **모니터링 알림**: CPU / 메모리 / 디스크 / 네트워크 지표 시계열 수집, 알림 규칙이 이메일, 패널, 위챗 워크(企业微信), 딩톡, 페이수(飞书) 그룹 봇 알림 지원
- **호스트 보안**: 보안 점수, 베이스라인 검사, 파일 무결성 모니터링（FIM）, 위협 탐지, 방화벽, 로그인 보안
- **앱 스토어**: 앱 분류 + 원클릭 설치 + 공식 템플릿 동기화
- **AI 스킬（Skill Hub）**: 스킬 검색, 설치, 업로드
- **웹 터미널**: WebSocket + pty 인터랙티브 셸, 다중 세션
- **일반 운영**: 웹사이트, 데이터베이스, 예약 작업, 파일 관리
- **이중 인증（2FA）**: 전역 스위치 + 사용자별 TOTP 바인딩
- **모니터링 내보내기**: Prometheus `/metrics` 엔드포인트（node_exporter 호환）
- **알림 관리**: SMTP / 위챗 워크 / 딩톡 / 페이수
- **설정 간소화**: JWT 키, Agent Token, AI 설정 모두 패널화, 설정 파일은 최소 항목만 유지
- **로그 시스템**: 로그 레벨 설정 가능（info / warn / error）, 로그 디스크 저장
- **계정 복구**: `-reset-pass` / `-reset-mfa` 서브 명령
- **7개 언어 i18n**: 간체 중국어 / 번체 중국어 / 영어 / 일본어 / 한국어 / 태국어 / 독일어
- **화이트 미니멀 UI**: 화이트 + 블랙 글꼴 배색, 브랜드 블루 포인트
- **이중 API**: `/api/v1`（브라우저용）+ `/agent/v1`（머신 간 표준 REST）
