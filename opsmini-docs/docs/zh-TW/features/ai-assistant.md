# AI 助手

OpsMini 內建 AI 大模型運維能力，用自然語言完成系統診斷、日誌分析與命令執行。

## 能力

- **自然語言診斷**：描述故障現象，AI 結合實時系統狀態給出診斷建議
- **日誌分析**：讓 AI 分析異常日誌、定位錯誤根因
- **命令執行**：AI 將自然語言意圖轉化為運維命令，經許可權確認後執行
- **深度思考**：可選「先思考後回答」模式，解決複雜推理問題
- **內建工具**：實時注入主機系統資訊（CPU/記憶體/磁碟/程序/埠/防火牆），並支援透過函式呼叫在 SkillHub 檢索與安裝技能

## 支援的 LLM 服務商

| Provider | 說明 |
|----------|------|
| `openai` | OpenAI 相容介面 |
| `deepseek` | DeepSeek |
| `qwen` | 通義千問（DashScope 相容介面） |
| `ollama` | 本地 Ollama 部署 |

## 配置

統一在**面板「設定 → AI 大模型接入」**中配置（原 `config.yaml` 的 `ai` 段已遷移到此，執行時即時生效）：

- 啟用 AI 助手（總開關）
- 模型服務商 / 模型名 / API Key / API 地址
- 自然語言執行操作 / 日誌智慧分析 / 告警智慧診斷 開關

> 配置優先順序：環境變數 `OPSMINI_AI_KEY` > 面板設定 > 配置檔案殘留的 `ai.*`。建議用環境變數存金鑰，避免落盤。詳見 [面板設定../configuration/panel-settings.md#ai-大模型接入。

## 安全機制

- AI 判定為「執行意圖」時，生成結構化 action + 引數
- 命中許可權白名單才執行；未授權 / 高危操作要求使用者二次確認
- 執行動作記錄審計日誌
- 關閉「啟用 AI 助手」開關後，AI 相關介面直接拒絕

## MCP 管理

支援配置 MCP（Model Context Protocol）服務，擴充套件 AI 助手的能力與資料來源。可在「AI 助手 → MCP」中增刪改查 MCP 配置，支援命令（stdio）與 URL（SSE/HTTP）兩種傳輸方式。

## 技能（Skill Hub）

內建「技能」標籤頁，對接 SkillHub 技能市場：

- 檢索、一鍵安裝技能
- 上傳本地技能、手動建立技能
- 啟用/禁用、刪除已安裝技能
