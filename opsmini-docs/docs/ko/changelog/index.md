# 변경 로그

각 버전의 변경 기록.

## v1.2.1 (2026-10-27)

**수정: 경계를 넘은 다중 호스트 AI 도구 4개 제거**

v1.2.0 은 `list_remote_hosts` / `remote_exec` / `remote_pull_file` / `remote_push_file` 네 개의 다중 호스트 도구를 등록해, 패널의 AI 가 OpsMini Server 의 컨트롤 플레인 HTTP API(4508)를 통해 다른 관리 대상 호스트로 명령과 파일을 보내도록 했습니다. 이 구현은 아키텍처 경계를 넘었기에 제거했습니다.

- 4508 은 OpsMini Server 가 OpsAnt 에게 제공하는 **내부** API 로, "로컬/내부망 전용"이며 인증을 검사하지 않습니다.
- 다중 호스트 경로에서 패널의 역할은 **관리 대상 Agent** 이며, 4507 의 gRPC 장기 연결로 Server 와 통신(등록·하트비트·작업 수신)해야 하고 컨트롤 플레인을 역으로 호출해서는 안 됩니다.
- 이 설계를 성립시키려면 4508 을 외부에 노출해야 하며, 이는 인증 없는 원격 명령 실행 입구를 인터넷에 두는 것과 같습니다.

따라서 도구는 **29개**(읽기 전용 16 / 저위험 쓰기 5 / 고위험 쓰기 8)로 돌아갑니다. 다중 호스트 오케스트레이션과 AI 는 OpsAnt 가 담당하며, 통합 실행 API(`/api/opsant/v1/tasks/run-shell/`, `tasks/run-script/`, `tasks/send-file/`, `tasks/get-minion-file/` 등)와 세 가지 실행 엔진을 보유합니다.

**마이그레이션 불필요**: 이 4개 도구는 이전 버전에서도 4508 도달 가능성을 전제로 했고 실제로 사용할 수 없었습니다.

## v1.2.0（2026-10-27）

**AI 에이전트: "운영 조언자"에서 "운영 수행자"로**

- **자체 개발한 경량 ReAct 커널**: Agent 프레임워크 없이 Reason → Act → Observe 루프를 구현해 단일 바이너리와 CGO 없는 빌드를 유지합니다. 한 턴은 기본 12단계로 제한되며, 초과하면 도구 호출을 멈추고 파악한 내용을 보고합니다
- **내장 도구 33개**: 읽기 전용 16개(시스템 개요 / 프로세스 / 포트 / 디스크 / 디렉터리 사용량 / 로그 검색 / 서비스 / 컨테이너 / 보안 등), 저위험 쓰기 5개, 고위험 쓰기 8개, 그리고 Agent 설정에 따라 동적으로 등록되는 다중 호스트 도구 4개
- **스트리밍 도구 호출**: `tool_calls` 조각을 index별로 누적해 이어 붙입니다. 스트리밍 도구 호출을 지원하지 않는 공급자는 자동으로 비스트리밍 재시도로 전환합니다
- **사고 과정 시각화**: 어떤 도구를 어떤 인자로 호출했고 어떤 원본 출력을 받았는지 단계별로 보여 주어 결론을 검증할 수 있습니다

**단계별 권한과 사람 개입**

- **4단계 위험 모델**: L0 읽기 전용은 자율 실행 / L1 저위험은 기본적으로 승인 필요(도구별로 승인 면제 가능) / L2 고위험은 매번 승인 필수이며 면제 불가 / L3 파괴적 작업은 패턴으로 강제 차단
- **L3는 실행 전에 차단**: `rm -rf /`, `mkfs`, `dd of=/dev/sd*`, fork 폭탄, 방화벽 전체 초기화, `/etc/passwd` 덮어쓰기 등은 관리자가 승인해도 실행되지 않습니다. 패널 자체 보호 규칙도 두 가지 추가(데이터 디렉터리 변경 금지, 패널 수신 포트 차단 금지)
- **중단과 재개**: 고위험 호출은 저장 후 보류되며, 채팅에서 승인하거나 거부하면 SQLite에서 메시지 열을 복원해 이어서 실행합니다. 거부 경로는 부작용이 없음을 실측으로 확인했습니다

**양방향 MCP**

- **MCP 클라이언트**: MCP 공식 Go SDK 기반으로 stdio와 Streamable HTTP 전송을 모두 지원합니다. 외부 MCP 서버의 도구는 `mcp__<서버>__<도구>` 형태로 자동 연결되며 설정을 2분마다 대조합니다
- **MCP 서버**: 자체 도구 집합을 `/mcp`에 게시하고 Bearer 토큰으로 인증합니다. 기본적으로 L0/L1 도구만 제공합니다(L2는 미승인 클라이언트에 노출하지 않습니다. 외부 클라이언트는 패널의 승인 대화상자를 표시할 수 없기 때문입니다)

**예약 AI 작업**

- **예약 작업에 네 번째 유형 "Agent 작업" 추가**: 프롬프트를 작성하면 cron에 따라 자동 실행됩니다. 스케줄, 활성화, 마지막 실행 시각, 실패 알림은 기존 체계를 그대로 사용합니다
- **무인 실행 시 권한 하향**: 옆에서 "승인"을 누를 사람이 없으므로 L2에 해당하는 도구는 즉시 거부되고 그 이유가 모델에 전달됩니다. 모델은 읽기 전용 도구로 전환해 작업을 마치고, 보고서에 "이 작업은 사람이 수행해야 함"과 실행 가능한 명령을 명시합니다
- **신뢰성과 비용 관리**: 작업별 단계 상한과 전체 타임아웃으로 이중 제한합니다. 3회 연속 실패하면 작업을 자동 비활성화하여 "매일 실패하고 매일 알림"을 막습니다. 패널에서 저장하면 실패 횟수가 초기화됩니다
- **내장 점검 프리셋 5종**: 호스트 점검 / 보안 점검 / 디스크 공간 / 서비스 상태 / 로그 이상, 그리고 자주 쓰는 주기 프리셋 4종

**단일 파일 HTML 보고서**

- **보고서는 자체 완결형 HTML 파일 하나**: 스타일은 인라인이며 스크립트, 외부 스타일시트, 웹 폰트, 이미지가 전혀 없습니다. USB 메모리, 메일 첨부, 임의의 정적 서버에서 그대로 표시됩니다
- **열기와 내려받기**: 작업 목록의 각 행에 "열기"(새 탭에서 바로 렌더링)와 "내려받기"를 제공합니다. 중국어 파일명은 RFC 5987로 인코딩합니다
- **데이터 디렉터리에 보관**: `<데이터 디렉터리>/reports/<작업명>/`에 `.html`과 `.md`를 함께 저장합니다. 모든 생성물은 기능별 하위 디렉터리로 모읍니다
- **안전한 렌더링**: 본문에는 호스트 데이터(로그 일부, 프로세스 명령줄, 설정값)가 섞여 있습니다. 렌더러는 문서 전체를 먼저 HTML 이스케이프한 뒤 인라인 규칙을 적용하고 http/https/mailto 링크만 허용하므로, 로그 속 `<script>`는 텍스트로 표시됩니다. 엄격한 CSP도 함께 전송합니다
- **PDF가 필요할 때**: 열린 보고서에서 브라우저의 "인쇄 → PDF로 저장"을 사용하십시오. 스타일시트에 인쇄 규칙이 포함되어 있습니다

**알림과 감사**

- **공용 알리미**: 기존 알림의 채널 분배를 공통 `Notifier`로 추출했습니다(패널 / 메일 / WeCom / DingTalk / Feishu). AI 작업과 알림이 완전히 동일하게 동작하며, 채널이 비어 있으면 패널 알림을 보냅니다
- **감사 기록**: AI 도구 호출은 감사 로그에 기록됩니다. 무인 실행에서 거부된 작업은 `unattended-deny`, 사람이 거부한 경우는 `reject:` 접두사로 남습니다

**기타 개선**

- 사이드바 버전 표시를 고정값 대신 백엔드의 실제 버전으로 변경
- AI 에이전트 설계 문서 `docs/ai-agent.md`를 7개 언어로 추가
- Agent 작업의 도구 정책은 관리자가 "AI 어시스턴트 → 도구 권한"에서 조정할 수 있습니다. 고위험 도구는 항상 "승인 필요"로 고정됩니다

## v1.1.0（2026-09-21）

**다중 호스트 관리（Agent / Server 아키텍처）**

- **Agent gRPC 클라이언트**: Agent가 OpsMini Server에 능동적으로 연결（단일 포트 gRPC 양방향 스트림）, 하트비트 + 지수 백오프 재연결, 실행 / 파일 작업 수신 및 결과 회신
- **OpsMini Server 측**: 등록 / 하트비트 / 연결 관리, 실행 작업 하달, 결과 수신（코드는 OpsAnt 프로젝트의 독립 Go 서브 프로젝트 `opsmini-server/`로 이전, OpsMini는 Agent만 유지）
- **명령 / 스크립트 실행**: command 및 셸 / python 스크립트, 결과（stdout / stderr / exit code / 소요 시간）회신
- **파일 가져오기（PullFile）**: Server가 Agent로부터 파일을 가져옴（청크 업로드 + size / md5 검증）
- **파일 배포（PushFile）**: Server가 Agent에게 파일을 배포（청크 + 이어받기 재개 + md5 검증）, 대상이 디렉터리인 경우 지원（원본 파일명 유지）
- **연결 상태 감지 + 장기 연결 유지**: Agent 온라인 / 오프라인 상태, 하트비트 타임아웃 판정, gRPC keepalive
- **OpsAnt 연동**: 패널 '설정' 페이지에서 OpsAnt 주소 / Token 시각적으로 구성（런타임 핫 스위칭, Token 표시는 눈 아이콘으로 평문 / 암호 전환 지원）, SSO 인증 없는 리다이렉트（기본 활성화）
- **`/agent/v1` REST API 제거**: gRPC 양방향 스트림으로 변경（기존 REST API 및 프론트엔드 'API Token' 설정 페이지도 함께 제거）

**패널 기능 강화**

- **파일 페이지 디렉터리 다운로드**: 디렉터리를 원클릭으로 zip 압축 다운로드（팝업 안내 + 디렉터리 크기 + 해당 파티션 디스크 사용률）
- **파일 페이지 디렉터리 삭제**: 디렉터리 재귀 삭제（위험 작업 팝업 + 디렉터리명 입력 2차 확인）
- **파일 페이지 긴 이름 최적화**: 매우 긴 파일 / 디렉터리명은 생략 표시, 마우스 오버 시 전체 이름 확인（가로 스크롤바 제거）
- **시스템 관리 '네트워크' 라우팅 테이블**: NIC 아래에 라우팅 테이블 추가 표시（대상 네트워크 / 게이트웨이 / 서브넷 마스크 / 플래그 / 인터페이스 / 메트릭）
- **MCP 구성 강화**: '구성 파일（JSON）'과 '테이블' 두 가지 입력 방식 지원；SSE / HTTP 방식은 사용자 정의 요청 헤더（여러 개）와 타임아웃 지원
- **방화벽 강화**: 활성화 전 패널 포트와 SSH 포트（22）를 자동 허용하여 활성화 후 접근 불가 방지；'설치되었으나 활성화되지 않은' ufw 식별
- **Prometheus 지표 강화**: `opsmini_cpu_usage_percent` / `opsmini_mem_usage_percent` 실시간 사용률, `node_procs_total` 총 프로세스 수 추가
- **확인 팝업 통일**: 모든 삭제 / 위험 작업을 플랫폼 자체 확인 팝업으로 변경（브라우저 네이티브 confirm 대체）

**터미널 최적화**

- **출력 여백**: 명령 출력 좌우 / 하단에 여백 추가, 더 이상 테두리에 붙지 않음
- **전체 화면 Esc 수정**: 전체 화면 모드에서 Esc를 눌러도 전체 화면이 종료되지 않음（vim 편집 모드의 Esc와 충돌 방지）
- **세션 유지**: 페이지 전환 후 터미널 세션이 재설정되지 않음（세션 유효 기간 내 유지）
- **문자 인코딩 설정**: 문자 집합 선택 추가（UTF-8 / GBK / GB18030 / Big5）, 중국어 깨짐 현상 해결

**사용성 최적화**

- **페이지 제목**: 'OpsMini · 접속 주소' 표시, 여러 탭 구분 가능
- **비밀번호 표시 여부**: 비밀번호 변경, OpsAnt Token 연동 등 입력란에 '표시 / 숨기기' 눈 아이콘 추가
- **설정 페이지 레이아웃**: '이중 인증'과 'OpsAnt 연동'을 나란히 표시, '자동 업데이트' 스위치 제거

## v1.0.0（2026-09-13）

OpsMini의 첫 공식 버전, 단일 바이너리 제공, 핵심 기능:

- **AI 운영**: 자연어 진단, 로그 지능형 분석, 명령 생성 및 실행（SSE 스트리밍 출력）, MCP 도구 연동
- **모니터링 알림**: CPU / 메모리 / 디스크 / 네트워크 지표 시계열 수집, 알림 규칙이 이메일, 패널, 위챗 워크(企业微信), 딩톡, 페이수(飞书) 그룹 봇 알림 지원
- **호스트 보안**: 보안 점수, 베이스라인 검사, 파일 무결성 모니터링（FIM）, 위협 탐지, 방화벽, 로그인 보안
- **앱 스토어**: 앱 분류 + 원클릭 설치 + 공식 템플릿 동기화
- **AI 스킬（Skill Hub）**: 스킬 검색, 설치, 업로드
- **웹 터미널**: WebSocket + pty 인터랙티브 셸, 다중 세션
- **일반 운영**: 웹사이트, 데이터베이스, 예약 작업, 파일 관리
- **이중 인증（2FA）**: 전역 스위치 + 사용자별 TOTP 바인딩
- **모니터링 내보내기**: Prometheus `/metrics` 엔드포인트（node_exporter 호환）
- **알림 관리**: SMTP / 위챗 워크 / 딩톡 / 페이수
- **설정 간소화**: JWT 키, Agent Token, AI 설정 모두 패널화, 설정 파일은 최소 항목만 유지
- **로그 시스템**: 로그 레벨 설정 가능（info / warn / error）, 로그 디스크 저장
- **계정 복구**: `-reset-pass` / `-reset-mfa` 서브 명령
- **7개 언어 i18n**: 간체 중국어 / 번체 중국어 / 영어 / 일본어 / 한국어 / 태국어 / 독일어
- **화이트 미니멀 UI**: 화이트 + 블랙 글꼴 배색, 브랜드 블루 포인트
- **이중 API**: `/api/v1`（브라우저용）+ `/agent/v1`（머신 간 표준 REST）
