# AI 助手

OpsMini 内置 AI 大模型运维能力。AI 助手不只是「能读系统信息的对话机器人」——它是一个**智能体（Agent）**：收到你的问题后，它会自主规划、调用工具取真实数据、观察结果并继续下一步，直到给出结论；而每一个有风险的操作，都必须先得到你的批准。

## 能力

- **自主多步排障**：描述故障现象，AI 自行串联多次工具调用（看指标 → 查进程 → 翻日志）后给出结论，而不是凭记忆作答
- **思考链可见**：每一步工具调用都以卡片呈现，可展开查看工具名、参数与原始输出，结论可追溯
- **29 个内置运维工具**：覆盖系统指标、进程、端口、磁盘、文件、日志、服务、容器、安全、计划任务等
- **分级授权 + 高危确认**：只读操作自主执行，高危操作弹窗等你在场点确认
- **双向 MCP**：既能接入外部 MCP 服务作为工具来源，也能把自身工具集发布为 MCP Server 供 Claude Desktop / Cursor 等调用
- **定时 AI 任务**：如每天早上自动做一次主机巡检，产出单文件 HTML 报告并推送到通知渠道
- **会话持久化**：对话落库，刷新页面或重启进程都能回看思考链；历史过长时自动压缩
- **技能（Skill Hub）**：从技能市场检索、安装、管理技能包

## 工具与风险分级

AI 能做的每一件事都由一个「工具」定义，每个工具带风险等级：

| 等级 | 含义 | 默认行为 |
|------|------|----------|
| **L0 只读** | 只读取信息，不改动系统 | 免确认，自主执行 |
| **L1 低危写** | 影响可控的写操作（清理临时文件、重启服务等） | 默认需确认，可在「工具权限」中单独放开 |
| **L2 高危写** | 执行命令、写文件、删文件、改 SSH、改防火墙等 | **每次都要人工批准**，不可设为免确认 |
| **L3 禁止** | 格式化磁盘、`rm -rf /`、清空防火墙规则等 | **执行前直接拦截**，即使批准也不执行 |

各等级的代表性工具：

| 等级 | 工具示例 |
|------|----------|
| L0 只读 | `sys_overview`、`list_processes`、`list_ports`、`list_disks`、`dir_usage`、`read_file`、`search_logs`、`query_metrics`、`docker_ps`、`security_status` |
| L1 低危写 | `clean_temp`、`clean_logs`、`service_control`、`docker_control`、`install_skill` |
| L2 高危写 | `exec_command`、`write_file`、`delete_path`、`modify_sshd`、`compress_dir`、`cron_write`、`kill_process`、`firewall_rule` |
| 多机（需配置） | `list_remote_hosts`、`remote_exec`、`remote_pull_file`、`remote_push_file` |

工具还受面板 RBAC 约束：只读角色看不到需要写权限的工具；L2 工具额外需要 `ai.agent.write` 权限。

在「AI 助手 → 工具权限」中可以看到完整清单，并按工具调整策略（**免确认 / 需确认 / 禁用**）。

## 人工确认

当 AI 需要执行高危操作时，它不会直接动手：

1. 对话流里出现一张**确认卡片**，写明工具名、完整参数和将要执行的命令（例如 `exec_command` 会展示完整命令行）；
2. 你点「批准执行」后，操作才会真正执行，结果回灌给 AI 继续推理；
3. 你点「拒绝」后，操作不会执行，AI 会收到拒绝原因并说明影响、给出替代方案。

确认请求默认 10 分钟过期。批准与拒绝都会记入审计日志。

## 安全机制

- **先扫描后执行**：每次工具调用前先做 L3 危险模式扫描，命中直接拒绝并把原因回灌给模型
- **面板自我保护**：任何会破坏面板自身（数据目录、面板监听端口）的操作一律拒绝
- **无人值守降级**：定时任务运行时没人在旁边点批准，因此 L2 操作会被自动拒绝并记入报告，任务继续跑完其余步骤
- **全程留痕**：工具调用、批准、拒绝都写入审计日志
- **总开关**：关闭「启用 AI 助手」后，AI 相关接口直接拒绝

> 产品判断：不提供无人值守的 root 自主智能体。目标形态是**「自主规划 + 分级授权」**——AI 负责调查和建议，破坏性操作由人授权。

## 定时 AI 任务

「AI 任务」不是独立入口，而是**计划任务的第四种类型**（与「面板任务 / 系统 crontab / 用户 crontab」并列）。这样调度、启停、上次执行时间、失败告警全部复用现有机制。

在**「计划任务 → 新建任务 → 任务类型选 Agent 任务」**中配置：

- **提示词**：描述要 AI 做什么。内置 5 个预设（主机巡检 / 安全巡检 / 磁盘空间巡检 / 服务状态巡检 / 日志异常巡检），点一下即填入
- **执行周期**：标准 cron 表达式，含常用预设（每天 08:00 等）
- **最大执行步数**：限制 AI 调用工具的次数，防长时间占用与消耗额度
- **通知渠道**：面板 / 邮件 / 企业微信 / 钉钉 / 飞书

任务列表每行提供「执行」（立即跑一次）与「报告」入口。任务连续失败 3 次会自动停用，避免「每天失败每天告警」。

## 报告

每次执行产出一个**单文件 HTML 报告**——样式内联、无脚本、无外部依赖，可以直接打开、当邮件附件、拷到任何地方都不会坏。

```
<数据目录>/reports/<任务名>/<任务名>-<时间戳>.html     ← 单文件报告
<数据目录>/reports/<任务名>/<任务名>-<时间戳>.md       ← 同一份内容的 Markdown
```

数据目录由**面板「设置 → 数据存储」**决定（默认 `/var/lib/opsmini/data`）。所有生成物都放在该目录下、按功能分子目录。

报告结构：执行摘要（状态 / 步数 / 工具调用）→ 任务指令 → 结论 → **附：执行过程**（每次工具调用一行，参数与观察结果并列，状态含「完成 / 被拒绝 / 硬禁止 / 失败」）。

任务行的两个入口：

- **打开** —— 新标签页直接渲染报告，不需要下载
- **下载** —— 保存为 `.html` 文件

需要 PDF 时，在打开的报告中用浏览器「打印 → 另存为 PDF」即可，样式表带打印规则，输出与屏幕一致。

## 支持的 LLM 服务商

| Provider | 说明 |
|----------|------|
| `openai` | OpenAI 兼容接口 |
| `deepseek` | DeepSeek |
| `qwen` | 通义千问（DashScope 兼容接口） |
| `ollama` | 本地 Ollama 部署 |

任何兼容 OpenAI `chat/completions` 协议的服务都可以接入。工具调用需模型支持 function calling；不支持的模型会自动降级为普通对话。

## 配置

统一在**面板「设置 → AI 大模型接入」**中配置（原 `config.yaml` 的 `ai` 段已迁移到此，运行时即时生效）：

- 启用 AI 助手（总开关）
- 模型服务商 / 模型名 / API Key / API 地址
- 自然语言执行操作 / 日志智能分析 / 告警智能诊断 开关

> 配置优先级：环境变量 `OPSMINI_AI_KEY` > 面板设置 > 配置文件残留的 `ai.*`。建议用环境变量存密钥，避免落盘。详见 [面板设置](../configuration/panel-settings.md#ai-config)。

配置完成后可在「AI 助手 → 工具权限」页顶部的运行参数中确认模型是否就绪（`model_ready`）。

## MCP 管理

### 作为客户端：使用外部工具

在「AI 助手 → MCP」中增删改查 MCP 服务，扩展 AI 的能力与数据源。支持两种传输方式：

- **命令（stdio）**：如本地运行的 MCP 服务进程
- **HTTP（Streamable HTTP）**：远程 MCP 服务，可自定义请求头

接入后，外部工具会以 `mcp__<服务名>__<工具名>` 的形式出现在工具清单中，风险等级依据服务声明的只读标记判定，每两分钟自动对账一次（改配置无需重启）。

### 作为服务端：让别的 AI 使用 OpsMini

面板也可以把自身的工具集发布出去，供 Claude Desktop、Cursor、OpsAnt 等 MCP 客户端调用：

- 端点为 `/mcp`（Streamable HTTP），使用**访问令牌**认证；令牌可在「AI 助手 → 工具权限」中查看、复制、重置
- **默认只下发只读与低危工具**。高危工具（执行命令、写文件等）不下发，因为外部客户端无法呈现面板的确认弹窗；确实需要时可在同一页开启「允许 MCP 高危操作」
- L3 禁止规则与面板自我保护对远程调用同样生效

## 技能（Skill Hub）

内置「技能」标签页，对接 SkillHub 技能市场：

- 检索、一键安装技能
- 上传本地技能、手动创建技能
- 启用/禁用、删除已安装技能
