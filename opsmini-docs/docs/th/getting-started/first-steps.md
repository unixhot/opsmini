# การล็อกอินครั้งแรกและการเริ่มต้น

หลังติดตั้งเสร็จ ทำตามขั้นตอนต่อไปนี้เพื่อล็อกอินครั้งแรกและเริ่มต้นความปลอดภัย

## 1. รับรหัสผ่านเริ่มต้น

ล็อกตอนเริ่มจะแสดงข้อมูลบัญชีเริ่มต้น:

```
initial admin account created: username=opsmini password=ggFKEX65ZVF6RNTm
```

รหัสผ่านยังสามารถดูได้ที่ `/data/opsmini/.init_passwd` (สิทธิ์ 600) ในไดเรกทอรีติดตั้ง

## 2. ล็อกอินพาเนล

1. เปิดเบราว์เซอร์ไปที่ `http://<host>:8888`
2. ป้อนชื่อผู้ใช้ `opsmini` และรหัสผ่านเริ่มต้น
3. หลังล็อกอินสำเร็จจะเข้าแดชบอร์ด

> ⚠️ ในสภาพแวดล้อม production ต้องเปิดพาเนลผ่าน [Reverse Proxy + HTTPS](../configuration/https.md) เพื่อหลีกเลี่ยงการส่งข้อมูลแบบข้อความล้วน

## 3. เปลี่ยนรหัสผ่าน

1. เข้า "การตั้งค่าส่วนตัว"
2. ตั้งรหัสผ่านใหม่ใน "เปลี่ยนรหัสผ่าน" แล้วบันทึก

เมื่อลืมรหัสผ่าน ให้ล็อกอินเข้าเซิร์ฟเวอร์แล้วรัน `opsmini -reset-pass <username>` เพื่อรีเซ็ต

## 4. ผูกการยืนตัวตนสองปัจจัย (แนะนำ)

1. เปิด 2FA รวมที่ "การตั้งค่า → การยืนยันตัวตนสองขั้นตอน" ของพาเนล
2. เข้าการตั้งค่าความปลอดภัยส่วนตัว สแกนเพื่อผูก TOTP authenticator (Google Authenticator / 1Password ฯลฯ)
3. ป้อนรหัสไดนามิกเพื่อผูกให้เสร็จ

หลังผูกแล้ว การล็อกอินแต่ละครั้งต้องป้อนรหัสไดนามิก 6 หลักเพิ่มเติม เพิ่มความปลอดภัยของบัญชีอย่างมาก เมื่อทำตัวตรวจสอบหายใช้ `opsmini -reset-mfa <username>` เพื่อกู้คืน

## 5. กำหนดค่าจุดเข้าความปลอดภัย (ทางเลือก)

ตั้งคำนำหน้าจุดเข้าความปลอดภัยใน "การตั้งค่า → การตั้งค่าพื้นฐาน" ของพาเนล (หรือแก้ไข `server.secret_entry` ใน `config.yaml` โดยตรง):

```yaml
server:
  secret_entry: "/opsmini_panel"
```

หลังกำหนดค่า ที่อยู่พาเนลจะเปลี่ยนเป็น `http://<host>:8888/opsmini_panel` ใช้ร่วมกับ reverse proxy เพื่อซ่อนจุดเข้าจริง ป้องกันการสแกนพอร์ต
