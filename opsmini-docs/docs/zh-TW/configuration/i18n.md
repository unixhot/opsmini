# 面板多語言

OpsMini 面板內建 7 種語言介面，無需額外配置即可切換。

## 支援的語言

| 語言 | 程式碼 |
|------|------|
| 簡體中文 | zh |
| 繁體中文 | zh-TW |
| English | en |
| 日本語 | ja |
| 한국어 | ko |
| ไทย | th |
| Deutsch | de |

## 切換方式

1. 登入面板後，點選頂欄右側的語言選擇器
2. 選擇目標語言，介面即時切換

> 語言偏好僅對當前會話生效，不影響其他使用者。

## 實現說明

- 前端語言包內聯於 Vue 3 SPA，`/api/v1/i18n/{lang}` 也可按需獲取
- 全部 7 語言在單二進位制中內建，無額外下載
