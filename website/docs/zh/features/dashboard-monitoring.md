# 仪表盘与监控

OpsMini 内置指标采集与监控告警能力，无需额外安装监控组件。

## 仪表盘

登录后默认进入仪表盘，展示：

- **资源概览**：CPU 使用率、内存占用、负载、磁盘、网络流量
- **实时时序**：CPU / 内存 / 磁盘 / 网络随时间变化曲线（ECharts 渲染）
- **系统状态**：运行时长、主机信息

指标采集器每 10 秒采样，内存环形缓冲保留 24 小时，历史数据降采样后落 SQLite（1 分钟粒度保留 7 天）。

## 监控

监控页提供：

- **时序查询**：按时间范围查看历史指标
- **告警规则**：自定义 CPU / 内存 / 磁盘 / 服务等指标的告警阈值与持续时间
- **告警事件**：查看已触发的告警事件与状态

### 告警规则示例

| 字段 | 说明 |
|------|------|
| 名称 | 规则名，如「CPU 持续过高」 |
| 指标 | `cpu` / `mem` / `disk` / `service` |
| 条件 | 如 `>90%` |
| 持续时长 | 触发前需持续满足的时间 |
| 通知方式 | 关联的通知渠道 |

## 通知

告警触发后可通过通知中心推送到管理员，支持站内通知与已读管理。

## Prometheus 集成

面板内置 node_exporter 兼容的 `/metrics` 端点，Prometheus 可直接 scrape，详见 [Prometheus 指标](../api/prometheus.md)。
