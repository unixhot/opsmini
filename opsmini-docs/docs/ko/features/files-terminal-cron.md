# 파일 / 터미널 / 예약 작업 / 로그

## 파일 관리

- 파일 시스템 디렉터리 탐색
- 파일 업로드 / 다운로드 / 이름 변경 / 삭제
- 새 디렉터리 생성

## 웹 터미널

- WebSocket + pty 기반의 SSH 유사 인터랙티브 터미널
- operator 이상 역할에게만 개방되며, 세션 기록이 감사됩니다

```text
프런트엔드 ws://host/api/v1/terminal?token=...
  → 서버 측에서 token + 역할 검증
  → pty 시작 → 양방향 데이터 포워딩
  → 종료 시 pty 회수, 세션 지속 시간 기록
```

## 예약 작업

세 가지 작업 유형:

| 유형 | 설명 | 작업 |
|------|------|------|
| 패널 작업 | 패널 상주 스케줄러가 관리（robfig/cron） | 추가·조회·수정·삭제 |
| 시스템 작업 | `/etc/crontab`、`/etc/cron.d/` | 읽기 전용 표시 + 제어된 편집 |
| 사용자 작업 | `/var/spool/cron/<user>` | 읽기 전용 표시 + 제어된 편집 |
