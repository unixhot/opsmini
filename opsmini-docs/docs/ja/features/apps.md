# アプリケーション管理

アプリケーション管理はウェブサイト、データベース、コンテナ、アプリストアの 4 種のリソースを統一的に扱います。

## ウェブサイト

- Nginx サイトと静的サイトの作成 / 管理
- ドメイン、実行環境（PHP / Node / 静的）、SSL 証明書の発行と更新の設定
- サイトの起動/停止と状態確認

## データベース

- MySQL、PostgreSQL データベースインスタンスの作成 / 管理
- データベース一覧、文字セットなどの設定の確認

## コンテナ（Docker）

- **コンテナ**：一覧、起動、停止、再起動、削除
- **イメージ**：イメージの確認と削除
- **ボリューム**：ボリュームの確認と削除
- **ネットワーク**：ネットワークの確認と削除

> Docker 管理にはホストマシンに Docker がインストールされ、`DOCKER_HOST` が設定されている必要があります。Docker クライアントの初期化に失敗した場合、パネルはグレースフルに機能を縮退し、コンテナのルートを非表示にします。

## アプリストア

- よく使うアプリのカテゴリを内蔵（Web サービス、データベース、キャッシュ、監視など）
- アプリのワンクリックインストール / アンインストール / 起動 / 停止 / 再起動（Docker Shell スクリプト）
- カスタムアプリテンプレートのインポートと公式テンプレートの同期に対応
