# 環境要件

## 対象ホスト

| 項目 | 最小要件 | 推奨 |
|----|----------|------|
| オペレーティングシステム | 主要な Linux ディストリビューション（x86_64 / aarch64） | Ubuntu 20.04+ / Debian 11+ / CentOS 7+ |
| CPU | 1 コア | 2 コア |
| メモリ | 512 MB | 1 GB+ |
| ディスク | 200 MB（バイナリ + データ） | 1 GB+（ログと SQLite を含む） |
| ネットワーク | 外部ネットワークにアクセス可能（初回ダウンロード） | 安定したイントラネットで可 |

## アーキテクチャ対応

| プラットフォーム | 用途 |
|------|------|
| `linux/amd64` | 主流の x86_64 サーバー（本番） |
| `linux/arm64` | ARM サーバー（Graviton / Raspberry Pi / Kunpeng / Phytium、本番） |
| `darwin/amd64` / `darwin/arm64` | macOS 開発マシン（開発・デバッグ専用。配布対象外） |

## 実行時依存

- **ゼロのランタイム依存**：フロントエンド、SQLite、静的リソースはすべてバイナリに埋め込まれており、PHP / Node / データベースのインストールは不要です
- Docker 管理機能にはホストマシンに Docker がインストールされている必要があります（パネル自体は Docker に依存しません）

## 権限

- ワンクリックインストールスクリプトには `root` または `sudo` が必要です
- パネルプロセスは専用の低権限ユーザー（例：`opsmini`）での実行を推奨します。詳しくは [systemd 管理](systemd.md) を参照してください
