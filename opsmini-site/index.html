Positioning

它不是面板，是装在你服务器上的 Agent

面板等你来点，Agent 自己动手。OpsMini 常驻在主机上，用一整套运维工具自行环视、判断、处理，只在需要你拍板时停下。

  • 你发现问题，你打开页面
  • 你逐项点开菜单去查

AI Agent

它不只是聊天，它会动手

OpsMini 内置自研 ReAct 智能体。接到问题后自主规划、连续调用运维工具查证，把每一步的工具、参数和原始输出都摊在你面前；按危险程度分级放权——该自己动手的自己动手，该问你的必须先问。

  • 自主多步排查：一次提问连查磁盘、进程、日志，直到定位到原因
  • 29 个内置工具：只读 / 低危写 / 高危写分级，覆盖系统、容器、服务、安全
  • 四级护栏：L0 自主、L1 可配置、L2 必须确认、L3 直接禁止（如 rm -rf /）
  • 定时巡检：排进计划任务，每天早上自动体检并归档单文件 HTML 报告
  • 双向 MCP：能调用外部 MCP 工具，也能把自身 29 个工具发布给 Claude / Cursor

Guardrails

它能动手，但你划得住线

每个工具按危险程度定级。只读的它自己看，破坏性的必须你点头，致命的直接禁止。无人值守时，凡需确认的一律拒绝，不猜你的意思。

L0
只读自主查指标、进程、端口、磁盘、日志。看什么都不会改变系统状态。
L1
低危需确认重启服务、清理临时文件。默认要你点一下，可按需放开。
L2
必须确认改配置、删数据、动网络。确认不可关闭，无人值守直接拒绝。
L3
直接禁止正则硬拦截致命命令（如 rm -rf /），并禁止它把自己关掉。
!每一次调用都进审计日志：谁触发的、调了什么工具、传了什么参数、返回了什么。想复盘随时查。

FAQ

常见问题

OpsMini 和宝塔、1Panel 有什么区别？

OpsMini 是常驻主机的 AI 运维 Agent，不是传统面板。页面只是它的观察窗：它能自主诊断并执行，提供 MCP 与机器对机器接口，纯 Go + SQLite 单文件交付。

支持哪些系统 / 架构？

Linux amd64 与 arm64（含树莓派、国产化服务器）。面板本身是静态编译的 Go 二进制，只要内核版本不是特别古老即可运行。

数据存在哪里？会丢吗？

所有配置、用户、审计、监控数据都存于同目录下的 SQLite 单文件（默认 opsmini.db），备份就是复制这个文件。监控指标持久化保留 30 天，重启不丢失。

AI 功能需要外接大模型吗？

AI 助手对接外部大模型服务，在「设置」中填入你的模型地址与密钥即可启用；不配置也不影响面板其他功能正常使用。

如何保证安全？

JWT 鉴权 + TOTP 两步验证（MFA）+ RBAC 角色权限 + 全量操作审计日志；登录安全分析会识别暴力破解与异常登录。建议公网部署时配合防火墙限制来源 IP。

它真的会自己改动我的系统吗？

会，但只在边界内：只读操作自主执行；低危写操作默认要你确认；改配置、删数据等高危动作必须逐次批准；致命命令执行前直接被拦截。每一次调用都写进审计日志。

需要连外网吗？数据会不会传出去？

除模型调用外全部本地完成：指标、审计、报告都留在主机本地磁盘。模型可以接你自建的 OpenAI 兼容接口或本地 Ollama，这种情况下数据完全不出机器。

和宝塔、1Panel 比，到底差在哪？

那些是「你操作的工具」，OpsMini 是「替你操作的同事」。它的页面更像观察窗和审批台——你可以什么都不点，它照样每天把活干完并留下报告。
