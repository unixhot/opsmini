# 機能ガイド

OpsMini の各機能モジュールの利用方法。

<div class="grid cards" markdown>

-   :material-view-dashboard-outline: **[ダッシュボードと監視](dashboard-monitoring.md)**

    ---

    リアルタイム指標、時系列グラフ、アラートルールとアラートイベント。

-   :material-robot-outline: **[AI アシスタント](ai-assistant.md)**

    ---

    自然言語運用、ログ分析、MCP 管理。

-   :material-shield-search: **[自律エージェント（イベントセンター）](autonomous-agent.md)**

    ---

    収集 → 集約 → ポリシー → 調査 → 検証のループ。攻撃チェーン、処理トランザクション、シャドウレビュー。

-   :material-file-document-alert-outline: **[変更検知](change-awareness.md)**

    ---

    誰が何をどう変えたか。ルール判定 + Agent による深掘り分析。

-   :material-pipe: **[ログパイプライン](log-pipeline.md)**

    ---

    Filebeat 設定互換の収集実行側。既定で無効、ES / Kafka / Logstash に対応。

-   :material-puzzle-outline: **[プラグインシステム](plugin-system.md)**

    ---

    独立プロセス + Unix socket、署名検証。業務機能を必要に応じて拡張。

-   :material-backup-restore: **[バックアップと復元](backup-restore.md)**

    ---

    ディレクトリ / MySQL / Redis のバックアップ。復元は事前チェック・自動スナップショット・ロールバック付き。

-   :material-apps: **[アプリケーション管理](apps.md)**

    ---

    ウェブサイト、データベース、コンテナ（Docker）、アプリストアの統一管理。

-   :material-console: **[ファイル / ターミナル / スケジュールタスク / ログ](files-terminal-cron.md)**

    ---

    ファイルの閲覧と編集、Web ターミナル、スケジュールタスク、ログ確認。

-   :material-server: **[システム管理](system.md)**

    ---

    プロセス、ネットワーク、ポート、ディスク、システムユーザー、ファイアウォール。

-   :material-account-cog-outline: **[ユーザーと権限](users-rbac.md)**

    ---

    ユーザー管理、RBAC ロールと権限ポイント。

-   :material-shield-check-outline: **[ホストセキュリティ](security.md)**

    ---

    ベースライン検査、ファイル整合性監視、脅威検出、ファイアウォール、ログインセキュリティ。

-   :material-tune-variant: **[パネル設定](../configuration/panel-settings.md)**

    ---

    基本設定、二段階認証、AI 大規模モデル接続、API Token、監視エクスポート、通知とログ保持。
