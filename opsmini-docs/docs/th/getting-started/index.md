## แนวคิดหลัก

| แนวคิด | คำอธิบาย |
|------|------|
| **พาเนลเครื่องเดียว** | แต่ละโฮสต์รันอินสแตนซ์ OpsMini หนึ่งตัวอิสระ ไม่พึ่งพาโหนดศูนย์กลาง |
| **ส่งมอบไบนารีเดียว** | frontend UI ฝังผ่าน `go:embed` การ deploy คือการคัดลอกไฟล์ปฏิบัติการหนึ่งไฟล์ |
| **API คู่** | `/api/v1` สำหรับ UI เบราว์เซอร์ (JWT + RBAC), `/agent/v1` สำหรับเครื่อง/การผสานรวมบุคคลที่สาม (Token + ไวท์ลิสต์คำสั่ง) |
| **การปฏิบัติการด้วยโมเดล AI** | วินิจฉัยด้วยภาษาธรรมชาติ วิเคราะห์ล็อก รันคำสั่ง เชื่อมต่อ OpenAI / DeepSeek / Qwen / Ollama |

## ขั้นตอนถัดไป

หลังติดตั้งเสร็จ แนะนำให้อ่านตามลำดับ:

1. [การติดตั้งและการ deploy](../installation/index.md) — ความต้องการระบบ การติดตั้งคลิกเดียว การ deploy ด้วยตนเอง Reverse Proxy
2. [คู่มือการกำหนดค่า](../configuration/index.md) — ไฟล์กำหนดค่า การจัดเก็บข้อมูล HTTPS
3. [คู่มือฟังก์ชัน](../features/index.md) — แดชบอร์ด AI assistant การจัดการแอปพลิเคชัน ความปลอดภัยของโฮสต์ ฯลฯ
4. [REST API](../api/index.md) — อินเทอร์เฟซการผสานรวมภายนอก
