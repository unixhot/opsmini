# 製品紹介

OpsMini は軽量な Linux ホスト運用管理パネルです（宝塔 / 1Panel に匹敵）。内蔵の AI 大規模モデル運用と外部向け標準 REST API を主要な差別化ポイントとしています。

## 位置づけ

| 観点 | 説明 |
|------|------|
| 対象シーン | 単一の Linux サーバー（1C1G の小型ホストでも動作可能） |
| 基本理念 | 1 台導入して 1 台管理。軽量、単一ホスト優先、連携可能 |
| 差別化 | AI 大規模モデル運用 + 標準 REST API |

## 主要機能

- **AI 大規模モデル運用**：自然言語で障害を診断、ログを分析、運用コマンドを実行。OpenAI / DeepSeek / Qwen / Ollama に接続
- **標準 REST API**：`/api/v1`（ブラウザ UI）と `/agent/v1`（マシン対マシン）で、監視プラットフォーム、自動化スクリプト、オーケストレーションツールとの連携に供する
- **Docker 管理**：コンテナ、イメージ、ボリューム、ネットワークの 4 種のリソース
- **Web ターミナル**：WebSocket + pty で実装した SSH ライクな対話型ターミナル
- **ホストセキュリティ**：ベースライン検査、ファイル整合性監視（FIM）、脅威検出、ファイアウォール、ログインセキュリティ
- **7 言語 i18n**：簡体字/繁体字中国語、英語、日本語、韓国語、タイ語、ドイツ語
- **単一バイナリ配布**：フロントエンドは `go:embed` で埋め込み、ゼロのランタイム依存

## 技術スタック

Go 1.25 · Gin · GORM · SQLite（純 Go）· Vue 3 · ECharts

## 類似製品との違い

| 機能 | 宝塔 / 1Panel | OpsMini |
|------|--------------|---------|
| 運用方法 | GUI による手動操作 | GUI + AI 自然言語運用 |
| 外部連携 | 標準 API なし | 標準 REST API（`/agent/v1`） |
| 監視連携 | node_exporter の別途インストールが必要 | `/metrics` を内蔵（node_exporter 互換） |
| 配布形態 | インストールスクリプト + 複数コンポーネント | 単一バイナリの静的リンク |
