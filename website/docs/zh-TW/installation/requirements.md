# 環境要求

## 目標主機

| 項 | 最低要求 | 推薦 |
|----|----------|------|
| 作業系統 | 主流 Linux 發行版（x86_64 / aarch64） | Ubuntu 20.04+ / Debian 11+ / CentOS 7+ |
| CPU | 1 核 | 2 核 |
| 記憶體 | 512 MB | 1 GB+ |
| 磁碟 | 200 MB（二進位制 + 資料） | 1 GB+（含日誌與 SQLite） |
| 網路 | 可訪問外網（首次下載） | 穩定內網即可 |

## 架構支援

| 平臺 | 用途 |
|------|------|
| `linux/amd64` | 主流 x86_64 伺服器（生產） |
| `linux/arm64` | ARM 伺服器（Graviton / 樹莓派 / 鯤鵬 / 飛騰，生產） |
| `darwin/amd64` / `darwin/arm64` | macOS 開發機（僅開發除錯，不交付） |

## 執行依賴

- **零執行時依賴**：前端、SQLite、靜態資源全部嵌入二進位制，無需安裝 PHP / Node / 資料庫
- Docker 管理功能需要宿主機已安裝 Docker（面板本身不依賴 Docker）

## 許可權

- 一鍵安裝指令碼需要 `root` 或 `sudo`
- 面板程序建議以專用低許可權使用者（如 `opsmini`）執行，詳見 [systemd 託管systemd.md
