# แดชบอร์ดและการมอนิเตอร์

OpsMini มีความสามารถการเก็บเมตริกและการแจ้งเตือนการมอนิเตอร์ในตัว ไม่ต้องติดตั้งคอมโพเนนต์มอนิเตอร์เพิ่มเติม

## แดชบอร์ด

หลังล็อกอินจะเข้าแดชบอร์ดเป็นค่าเริ่มต้น แสดง:

- **ภาพรวมทรัพยากร**: อัตราการใช้ CPU หน่วยความจำ โหลด ดิสก์ ปริมาณการรับส่งเครือข่าย
- **อนุกรมเวลาเรียลไทม์**: เส้นโค้งการเปลี่ยนแปลงของ CPU / หน่วยความจำ / ดิสก์ / เครือข่ายตามเวลา (เรนเดอร์ด้วย ECharts)
- **สถานะระบบ**: ระยะเวลาทำงาน ข้อมูลโฮสต์

ตัวเก็บเมตริกสุ่มตัวอย่างทุก 10 วินาที ring buffer ในหน่วยความจำเก็บ 24 ชั่วโมง ข้อมูลประวัติหลังลดความถี่แล้วเก็บลง SQLite (ความละเอียด 1 นาที เก็บ 7 วัน)

## การมอนิเตอร์

หน้าการมอนิเตอร์มี:

- **การสอบถามอนุกรมเวลา**: ดูเมตริกประวัติตามช่วงเวลา
- **กฎการแจ้งเตือน**: กำหนดค่าเกณฑ์และระยะเวลาการแจ้งเตือนของเมตริก CPU / หน่วยความจำ / ดิสก์ / บริการ ฯลฯ ได้เอง
- **เหตุการณ์การแจ้งเตือน**: ดูเหตุการณ์การแจ้งเตือนที่ถูกทริกเกอร์และสถานะ

### ตัวอย่างกฎการแจ้งเตือน

| ฟิลด์ | คำอธิบาย |
|------|------|
| ชื่อ | ชื่อกฎ เช่น "CPU สูงต่อเนื่อง" |
| เมตริก | `cpu` / `mem` / `disk` / `service` |
| เงื่อนไข | เช่น `>90%` |
| ระยะเวลาต่อเนื่อง | เวลาที่ต้องเป็นจริงต่อเนื่องก่อนทริกเกอร์ |
| วิธีแจ้งเตือน | ช่องทางการแจ้งเตือนที่เชื่อมโยง |

## การแจ้งเตือน

เมื่อการแจ้งเตือนถูกทริกเกอร์ สามารถส่งถึงผู้ดูแลผ่านศูนย์การแจ้งเตือน รองรับการแจ้งเตือนภายในไซต์และการจัดการสถานะอ่านแล้ว

## การผสานรวม Prometheus

พาเนลมีเอนด์พอยต์ `/metrics` ที่เข้ากันได้กับ node_exporter ในตัว Prometheus สามารถ scrape ได้โดยตรง ดูรายละเอียดที่ [Prometheus metrics](../api/prometheus.md)
