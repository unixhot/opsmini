# AI アシスタント

OpsMini には AI 大規模モデルによる運用機能が内蔵されており、自然言語でシステム診断、ログ分析、コマンド実行を行えます。

## 機能

- **自然言語による診断**：障害の現象を説明すると、AI がリアルタイムのシステム状態と組み合わせて診断アドバイスを提示
- **ログ分析**：AI に異常ログを分析させ、エラーの根本原因を特定
- **コマンド実行**：AI が自然言語の意図を運用コマンドに変換し、権限確認後に実行
- **深い思考**：任意の「考えてから回答する」モードで、複雑な推論問題を解決
- **内蔵ツール**：ホストのシステム情報（CPU/メモリ/ディスク/プロセス/ポート/ファイアウォール）をリアルタイムで注入し、関数呼び出しによる SkillHub でのスキル検索とインストールにも対応

## 対応 LLM プロバイダ

| Provider | 説明 |
|----------|------|
| `openai` | OpenAI 互換インターフェース |
| `deepseek` | DeepSeek |
| `qwen` | 通義千問（DashScope 互換インターフェース） |
| `ollama` | ローカル Ollama デプロイ |

## 設定

**パネル「設定 → AI 大規模モデル接続」**で一元設定します（従来の `config.yaml` の `ai` セクションはここに移行済みで、ランタイムで即時反映）：

- AI アシスタントを有効化（マスタースイッチ）
- モデルプロバイダ / モデル名 / API Key / API アドレス
- 自然言語での操作実行 / ログのインテリジェント分析 / アラートのインテリジェント診断のスイッチ

> 設定の優先順位：環境変数 `OPSMINI_AI_KEY` > パネル設定 > 設定ファイルに残存する `ai.*`。シークレットのディスク保存を避けるため、環境変数での保存を推奨します。詳しくは [パネル設定](../configuration/panel-settings.md#ai-config)。

## セキュリティ機構

- AI が「実行意図」と判定すると、構造化された action + パラメータを生成
- 権限ホワイトリストに一致した場合のみ実行。未許可 / 高リスク操作はユーザーの二次確認が必要
- 実行アクションは監査ログに記録
- 「AI アシスタントを有効化」スイッチをオフにすると、AI 関連インターフェースは直接拒否されます

## MCP 管理

MCP（Model Context Protocol）サービスの設定に対応し、AI アシスタントの機能とデータソースを拡張できます。「AI アシスタント → MCP」で MCP 設定を追加・削除・変更・照会でき、コマンド（stdio）と URL（SSE/HTTP）の 2 種類の転送方式に対応しています。

## スキル（Skill Hub）

「スキル」タブが内蔵されており、SkillHub スキルマーケットに接続します：

- スキルの検索、ワンクリックインストール
- ローカルスキルのアップロード、スキルの手動作成
- インストール済みスキルの有効化/無効化、削除
