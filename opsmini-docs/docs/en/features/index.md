# Features Guide

Usage instructions for each OpsMini feature module.

-   :material-server: **[System Management](system.md)**

-   :material-account-cog-outline: **[Users & Permissions](users-rbac.md)**

-   :material-shield-check-outline: **[Host Security](security.md)**

    ---

-   :material-tune-variant: **[Panel Settings](../configuration/panel-settings.md)**

    ---

    Basic settings, two-step verification, AI model integration, API Token, monitoring export, notifications and log retention.
