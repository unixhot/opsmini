# 应用管理

应用管理统一承载网站、数据库、容器与软件商店四类资源。

## 网站

- 创建 / 管理 Nginx 站点与静态站点
- 配置域名、运行环境（PHP / Node / 静态）、SSL 证书签发与续期
- 站点启停与状态查看

## 数据库

- 创建 / 管理 MySQL、PostgreSQL 数据库实例
- 查看数据库列表、字符集等配置

## 容器（Docker）

- **容器**：列表、启动、停止、重启、删除
- **镜像**：查看与删除镜像
- **卷**：查看与删除卷
- **网络**：查看与删除网络

> Docker 管理需要宿主机已安装 Docker 并配置好 `DOCKER_HOST`；若 Docker 客户端初始化失败，面板会优雅降级并隐藏容器路由。

## 软件商店

- 内置常用应用分类（Web 服务、数据库、缓存、监控等）
- 应用一键安装 / 卸载 / 启动 / 停止 / 重启（Docker Shell 脚本）
- 支持自定义应用模板导入与官方模板同步
