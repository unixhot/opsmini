## Web 终端

- 基于 WebSocket + pty 的类 SSH 交互终端
- 仅对 operator 及以上角色开放，会话记录审计

```text
前端 ws://host/api/v1/terminal?token=...
  → 服务端校验 token + 角色
  → 启动 pty → 双向数据转发
  → 关闭时回收 pty、记录会话时长
```

## 计划任务

三类任务：

| 类型 | 说明 | 操作 |
|------|------|------|
| 面板任务 | 由面板常驻调度（robfig/cron） | 增删改查 |
| 系统任务 | `/etc/crontab`、`/etc/cron.d/` | 只读展示 + 受控编辑 |
| 用户任务 | `/var/spool/cron/<user>` | 只读展示 + 受控编辑 |
