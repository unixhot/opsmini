# คู่มือฟังก์ชัน

คำอธิบายการใช้งานโมดูลฟังก์ชันต่าง ๆ ของ OpsMini

<div class="grid cards" markdown>

-   :material-view-dashboard-outline: **[แดชบอร์ดและการมอนิเตอร์](dashboard-monitoring.md)**

    ---

    เมตริกเรียลไทม์ แผนภูมิอนุกรมเวลา กฎการแจ้งเตือนและเหตุการณ์การแจ้งเตือน

-   :material-robot-outline: **[AI assistant](ai-assistant.md)**

    ---

    การปฏิบัติการด้วยภาษาธรรมชาติ การวิเคราะห์ล็อก การจัดการ MCP

-   :material-apps: **[การจัดการแอปพลิเคชัน](apps.md)**

    ---

    การจัดการเว็บไซต์ ฐานข้อมูล คอนเทนเนอร์ (Docker) ร้านซอฟต์แวร์อย่างเป็นเอกภาพ

-   :material-console: **[ไฟล์ / เทอร์มินัล / งานตามกำหนดเวลา / ล็อก](files-terminal-cron.md)**

    ---

    การเรียกดูและแก้ไขไฟล์ เว็บเทอร์มินัล งานตามกำหนดเวลา การดูล็อก

-   :material-server: **[การจัดการระบบ](system.md)**

    ---

    โปรเซส เน็ตเวิร์ก พอร์ต ดิสก์ ผู้ใช้ระบบ ไฟร์วอลล์

-   :material-account-cog-outline: **[ผู้ใช้และสิทธิ์](users-rbac.md)**

    ---

    การจัดการผู้ใช้ บทบาท RBAC และจุดสิทธิ์

-   :material-shield-check-outline: **[ความปลอดภัยของโฮสต์](security.md)**

    ---

    การตรวจสอบ baseline การมอนิเตอร์ความสมบูรณ์ของไฟล์ การตรวจจับภัยคุกคาม ไฟร์วอลล์ ความปลอดภัยการล็อกอิน

-   :material-tune-variant: **[การตั้งค่าพาเนล](../configuration/panel-settings.md)**

    ---

    การตั้งค่าพื้นฐาน การยืนยันตัวตนสองขั้นตอน การเชื่อมต่อโมเดล AI, API Token, การส่งออกมอนิเตอร์, การแจ้งเตือนและการเก็บรักษาล็อก

</div>
