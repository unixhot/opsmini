# AI assistant

OpsMini มีความสามารถการปฏิบัติการด้วยโมเดล AI ในตัว ใช้ภาษาธรรมชาติในการวินิจฉัยระบบ วิเคราะห์ล็อก และรันคำสั่ง

## ความสามารถ

- **การวินิจฉัยด้วยภาษาธรรมชาติ**: อธิบายอาการของปัญหา AI จะให้คำแนะนำการวินิจฉัยโดยอ้างอิงสถานะระบบเรียลไทม์
- **การวิเคราะห์ล็อก**: ให้ AI วิเคราะห์ล็อกที่ผิดปกติ ระบุสาเหตุของข้อผิดพลาด
- **การรันคำสั่ง**: AI แปลงความตั้งใจจากภาษาธรรมชาติเป็นคำสั่งปฏิบัติการ แล้วรันหลังได้รับการยืนยันสิทธิ์
- **การคิดเชิงลึก**: เลือกโหมด "คิดก่อนแล้วค่อยตอบ" เพื่อแก้ปัญหาการให้เหตุผลที่ซับซ้อน
- **เครื่องมือในตัว**: ฉีดข้อมูลระบบของโฮสต์แบบเรียลไทม์ (CPU/หน่วยความจำ/ดิสก์/โปรเซส/พอร์ต/ไฟร์วอลล์) และรองรับการค้นหาและติดตั้งทักษะใน SkillHub ผ่าน function call

## ผู้ให้บริการ LLM ที่รองรับ

| Provider | คำอธิบาย |
|----------|------|
| `openai` | อินเทอร์เฟซที่เข้ากันได้กับ OpenAI |
| `deepseek` | DeepSeek |
| `qwen` | Tongyi Qianwen (อินเทอร์เฟซที่เข้ากันได้กับ DashScope) |
| `ollama` | การ deploy ด้วย Ollama ในเครื่อง |

## การกำหนดค่า

กำหนดค่าที่เดียวใน**พาเนล "การตั้งค่า → การเชื่อมต่อโมเดล AI"** (ส่วน `ai` เดิมใน `config.yaml` ย้ายมาที่นี่แล้ว มีผลทันทีตอนรันไทม์):

- เปิดใช้ AI assistant (สวิตช์รวม)
- ผู้ให้บริการโมเดล / ชื่อโมเดล / API Key / ที่อยู่ API
- สวิตช์การรันคำสั่งด้วยภาษาธรรมชาติ / การวิเคราะห์ล็อกอัจฉริยะ / การวินิจฉัยการแจ้งเตือนอัจฉริยะ

> ลำดับความสำคัญของการกำหนดค่า: ตัวแปรสภาพแวดล้อม `OPSMINI_AI_KEY` > การตั้งค่าพาเนล > `ai.*` ที่เหลือในไฟล์กำหนดค่า แนะนำให้เก็บคีย์ในตัวแปรสภาพแวดล้อมเพื่อหลีกเลี่ยงการเก็บลงดิสก์ ดูรายละเอียดที่ [การตั้งค่าพาเนล](../configuration/panel-settings.md#ai-config)

## กลไกความปลอดภัย

- เมื่อ AI ตัดสินว่าเป็น "ความตั้งใจที่จะรัน" จะสร้าง action + พารามิเตอร์แบบมีโครงสร้าง
- จะรันเฉพาะเมื่อตรงกับไวท์ลิสต์สิทธิ์; การดำเนินการที่ไม่ได้รับอนุญาต / ความเสี่ยงสูงต้องให้ผู้ใช้ยืนยันครั้งที่สอง
- การดำเนินการจะถูกบันทึกในล็อกการตรวจสอบ
- เมื่อปิดสวิตช์ "เปิดใช้ AI assistant" อินเทอร์เฟซที่เกี่ยวข้องกับ AI จะถูกปฏิเสธโดยตรง

## การจัดการ MCP

รองรับการกำหนดค่าบริการ MCP (Model Context Protocol) เพื่อขยายความสามารถและแหล่งข้อมูลของ AI assistant สามารถเพิ่ม/ลบ/แก้ไข/สอบถามการกำหนดค่า MCP ได้ใน "AI assistant → MCP" รองรับการส่งข้อมูลสองแบบคือคำสั่ง (stdio) และ URL (SSE/HTTP)

## ทักษะ (Skill Hub)

มีแท็บ "ทักษะ" ในตัว เชื่อมต่อกับตลาดทักษะ SkillHub:

- ค้นหา ติดตั้งทักษะได้ในคลิกเดียว
- อัปโหลดทักษะท้องถิ่น สร้างทักษะด้วยตนเอง
- เปิด/ปิด ลบทักษะที่ติดตั้งแล้ว
