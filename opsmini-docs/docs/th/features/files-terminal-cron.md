# ไฟล์ / เทอร์มินัล / งานตามกำหนดเวลา / ล็อก

## การจัดการไฟล์

- เรียกดูไดเรกทอรีระบบไฟล์
- อัปโหลด / ดาวน์โหลด / เปลี่ยนชื่อ / ลบไฟล์
- สร้างไดเรกทอรีใหม่

## เว็บเทอร์มินัล

- เทอร์มินัลโต้ตอบคล้าย SSH บนพื้นฐาน WebSocket + pty
- เปิดให้เฉพาะบทบาท operator ขึ้นไป บันทึกเซสชันเพื่อการตรวจสอบ

```text
frontend ws://host/api/v1/terminal?token=...
  → เซิร์ฟเวอร์ตรวจสอบ token + บทบาท
  → เริ่ม pty → ส่งต่อข้อมูลสองทิศทาง
  → เมื่อปิด เก็บคืน pty บันทึกระยะเวลาเซสชัน
```

## งานตามกำหนดเวลา

งานสามประเภท:

| ประเภท | คำอธิบาย | การดำเนินการ |
|------|------|------|
| งานพาเนล | ถูกจัดตารางโดยพาเนลตลอดเวลา (robfig/cron) | เพิ่ม/ลบ/แก้ไข/สอบถาม |
| งานระบบ | `/etc/crontab`, `/etc/cron.d/` | แสดงแบบอ่านอย่างเดียว + แก้ไขแบบควบคุม |
| งานผู้ใช้ | `/var/spool/cron/<user>` | แสดงแบบอ่านอย่างเดียว + แก้ไขแบบควบคุม |

## ล็อก

- ดูรายการล็อกของพาเนล
- ล็อก tail แบบเรียลไทม์
- ล็อกแบบมีโครงสร้าง (zerolog) แบ่งระดับ
