# 主機安全

OpsMini 內建主機安全中心，提供五大安全能力。

## 安全概覽

安全中心首頁聚合展示整體安全態勢，包括基線合規度、檔案變更、威脅發現、防火牆狀態、登入安全等。

## 基線檢查

- 對主機執行安全基線掃描（如密碼策略、SSH 配置、系統加固項）
- 檢視最近一次掃描結果與不符合項
- 一鍵發起掃描

## 檔案完整性監控（FIM）

- 為關鍵檔案 / 目錄建立基線
- 檢測檔案的增刪改變化並記錄事件
- 支援重建基線、檢視變更事件

## 威脅檢測

- 掃描主機威脅（異常程序、可疑檔案等）
- 檢視威脅發現列表
- 標記威脅為已處理

## 防火牆

- 檢視防火牆狀態
- 開啟 / 關閉防火牆
- 放行 / 拒絕埠、刪除規則

## 登入安全

- 分析登入行為（成功 / 失敗、來源 IP）
- 檢視 SSH 登入記錄
- 配合登入失敗限流與鎖定

## 相關許可權點

安全操作受 RBAC 許可權點控制：`security.scan`、`security.firewall`、`security.fim`、`security.threat`。
