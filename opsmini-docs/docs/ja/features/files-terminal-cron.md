- ディレクトリの新規作成

## Web ターミナル

- WebSocket + pty をベースとした SSH ライクな対話型ターミナル
- operator 以上のロールのみ利用可能。セッションは監査に記録

```text
フロントエンド ws://host/api/v1/terminal?token=...
  → サーバー側で token + ロールを検証
  → pty を起動 → 双方向データ転送
  → クローズ時に pty を回収、セッション時間を記録
```

## スケジュールタスク

3 種類のタスクがあります：

| 種別 | 説明 | 操作 |
|------|------|------|
| パネルタスク | パネルが常駐スケジューリング（robfig/cron） | 追加・削除・変更・照会 |
| システムタスク | `/etc/crontab`、`/etc/cron.d/` | 読み取り専用表示 + 制御された編集 |
| ユーザータスク | `/var/spool/cron/<user>` | 読み取り専用表示 + 制御された編集 |
