# ความต้องการสภาพแวดล้อม

## โฮสต์เป้าหมาย

| รายการ | ความต้องการขั้นต่ำ | แนะนำ |
|----|----------|------|
| ระบบปฏิบัติการ | Linux distribution หลัก (x86_64 / aarch64) | Ubuntu 20.04+ / Debian 11+ / CentOS 7+ |
| CPU | 1 คอร์ | 2 คอร์ |
| หน่วยความจำ | 512 MB | 1 GB+ |
| ดิสก์ | 200 MB (ไบนารี + ข้อมูล) | 1 GB+ (รวมล็อกและ SQLite) |
| เครือข่าย | เข้าถึงอินเทอร์เน็ตได้ (ดาวน์โหลดครั้งแรก) | อินทราเน็ตเสถียรก็พอ |

## การรองรับสถาปัตยกรรม

| แพลตฟอร์ม | วัตถุประสงค์ |
|------|------|
| `linux/amd64` | เซิร์ฟเวอร์ x86_64 หลัก (production) |
| `linux/arm64` | เซิร์ฟเวอร์ ARM (Graviton / Raspberry Pi / Kunpeng / Phytium, production) |
| `darwin/amd64` / `darwin/arm64` | เครื่องพัฒนา macOS (ใช้สำหรับพัฒนาดีบักเท่านั้น ไม่ส่งมอบ) |

## ไลบรารีรันไทม์

- **ไม่มีไลบรารีรันไทม์**: frontend, SQLite, ทรัพยากร static ทั้งหมดฝังในไบนารี ไม่ต้องติดตั้ง PHP / Node / ฐานข้อมูล
- ฟังก์ชันจัดการ Docker ต้องติดตั้ง Docker บนโฮสต์ (ตัวพาเนลเองไม่พึ่งพา Docker)

## สิทธิ์

- สคริปต์ติดตั้งคลิกเดียวต้องใช้ `root` หรือ `sudo`
- แนะนำให้รันโปรเซสพาเนลด้วยผู้ใช้สิทธิ์ต่ำเฉพาะ (เช่น `opsmini`) ดูรายละเอียดที่ [จัดการด้วย systemd](systemd.md)
