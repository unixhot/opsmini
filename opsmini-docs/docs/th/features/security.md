# ความปลอดภัยของโฮสต์

OpsMini มีศูนย์ความปลอดภัยของโฮสต์ในตัว ให้ความสามารถด้านความปลอดภัยห้าประการ

## ภาพรวมความปลอดภัย

หน้าแรกของศูนย์ความปลอดภัยแสดงภาพรวมสถานการณ์ความปลอดภัยโดยรวม รวมถึงระดับความสอดคล้องของ baseline การเปลี่ยนแปลงไฟล์ การค้นพบภัยคุกคาม สถานะไฟร์วอลล์ ความปลอดภัยการล็อกอิน ฯลฯ

## การตรวจสอบ baseline

- สแกน baseline ความปลอดภัยของโฮสต์ (เช่น นโยบายรหัสผ่าน การกำหนดค่า SSH รายการเสริมความแข็งแกร่งของระบบ)
- ดูผลการสแกนล่าสุดและรายการที่ไม่เป็นไปตามเกณฑ์
- เริ่มการสแกนได้ในคลิกเดียว

## การมอนิเตอร์ความสมบูรณ์ของไฟล์ (FIM)

- สร้าง baseline สำหรับไฟล์ / ไดเรกทอรีสำคัญ
- ตรวจจับการเปลี่ยนแปลงเพิ่ม/ลบ/แก้ไขของไฟล์และบันทึกเหตุการณ์
- รองรับการสร้าง baseline ใหม่ การดูเหตุการณ์การเปลี่ยนแปลง

## การตรวจจับภัยคุกคาม

- สแกนภัยคุกคามของโฮสต์ (โปรเซสผิดปกติ ไฟล์น่าสงสัย ฯลฯ)
- ดูรายการภัยคุกคามที่พบ
- ทำเครื่องหมายภัยคุกคามว่าจัดการแล้ว

## ไฟร์วอลล์

- ดูสถานะไฟร์วอลล์
- เปิด / ปิดไฟร์วอลล์
- อนุญาต / ปฏิเสธพอร์ต ลบกฎ

## ความปลอดภัยการล็อกอิน

- วิเคราะห์พฤติกรรมการล็อกอิน (สำเร็จ / ล้มเหลว, IP ต้นทาง)
- ดูบันทึกการล็อกอิน SSH
- ใช้ร่วมกับการจำกัดอัตราและการล็อกเมื่อล็อกอินล้มเหลว

## จุดสิทธิ์ที่เกี่ยวข้อง

การดำเนินการด้านความปลอดภัยถูกควบคุมโดยจุดสิทธิ์ RBAC: `security.scan`, `security.firewall`, `security.fim`, `security.threat`
