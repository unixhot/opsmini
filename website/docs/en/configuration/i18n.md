# Panel Languages

The OpsMini panel ships 7 UI languages — no extra configuration needed.

## Supported Languages

| Language | Code |
|----------|------|
| 简体中文 | zh |
| 繁體中文 | zh-TW |
| English | en |
| 日本語 | ja |
| 한국어 | ko |
| ไทย | th |
| Deutsch | de |

## Switching

1. Log in and click the language selector in the top bar.
2. Pick a language; the UI switches instantly.

> Language preference applies to the current session only.

## Implementation Notes

- Language packs are inlined in the Vue 3 SPA; `/api/v1/i18n/{lang}` is also available.
- All 7 languages are embedded in the single binary.
