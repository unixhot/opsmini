# 面板多语言

OpsMini 面板内置 7 种语言界面，无需额外配置即可切换。

## 支持的语言

| 语言 | 代码 |
|------|------|
| 简体中文 | zh |
| 繁體中文 | zh-TW |
| English | en |
| 日本語 | ja |
| 한국어 | ko |
| ไทย | th |
| Deutsch | de |

## 切换方式

1. 登录面板后，点击顶栏右侧的语言选择器
2. 选择目标语言，界面即时切换

> 语言偏好仅对当前会话生效，不影响其他用户。

## 实现说明

- 前端语言包内联于 Vue 3 SPA，`/api/v1/i18n/{lang}` 也可按需获取
- 全部 7 语言在单二进制中内置，无额外下载
