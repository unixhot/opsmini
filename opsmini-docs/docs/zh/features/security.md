# 主机安全

OpsMini 内置主机安全中心，提供五大安全能力。

## 安全概览

安全中心首页聚合展示整体安全态势，包括基线合规度、文件变更、威胁发现、防火墙状态、登录安全等。

## 基线检查

- 对主机执行安全基线扫描（如密码策略、SSH 配置、系统加固项）
- 查看最近一次扫描结果与不符合项
- 一键发起扫描

## 文件完整性监控（FIM）

- 为关键文件 / 目录建立基线
- 检测文件的增删改变化并记录事件
- 支持重建基线、查看变更事件

## 威胁检测

- 扫描主机威胁（异常进程、可疑文件等）
- 查看威胁发现列表
- 标记威胁为已处理

## 防火墙

- 查看防火墙状态
- 开启 / 关闭防火墙
- 放行 / 拒绝端口、删除规则

## 登录安全

- 分析登录行为（成功 / 失败、来源 IP）
- 查看 SSH 登录记录
- 配合登录失败限流与锁定

## 相关权限点

安全操作受 RBAC 权限点控制：`security.scan`、`security.firewall`、`security.fim`、`security.threat`。
