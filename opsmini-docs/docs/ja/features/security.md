# ホストセキュリティ

OpsMini にはホストセキュリティセンターが内蔵されており、5 つのセキュリティ機能を提供します。

## セキュリティ概要

セキュリティセンターのトップページには全体のセキュリティ状況が集約表示されます。ベースライン準拠度、ファイル変更、脅威の発見、ファイアウォール状態、ログインセキュリティなどが含まれます。

## ベースライン検査

- ホストに対してセキュリティベースラインのスキャンを実行（例：パスワードポリシー、SSH 設定、システム強化項目）
- 直近のスキャン結果と不適合項目を確認
- ワンクリックでスキャンを開始

## ファイル整合性監視（FIM）

- 重要なファイル / ディレクトリにベースラインを確立
- ファイルの追加・削除・変更を検出してイベントを記録
- ベースラインの再構築、変更イベントの確認に対応

## 脅威検出

- ホストの脅威をスキャン（異常プロセス、不審ファイルなど）
- 脅威の発見一覧を確認
- 脅威を処理済みとしてマーク

## ファイアウォール

- ファイアウォール状態の確認
- ファイアウォールの有効化 / 無効化
- ポートの許可 / 拒否、ルールの削除

## ログインセキュリティ

- ログイン行動の分析（成功 / 失敗、送信元 IP）
- SSH ログイン記録の確認
- ログイン失敗のレート制限とロックの併用

## 関連する権限ポイント

セキュリティ操作は RBAC 権限ポイントで制御されます：`security.scan`、`security.firewall`、`security.fim`、`security.threat`。
