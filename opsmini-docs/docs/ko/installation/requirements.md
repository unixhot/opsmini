# 환경 요구 사항

## 대상 호스트

| 항목 | 최소 요구 사항 | 권장 |
|----|----------|------|
| 운영체제 | 주요 Linux 배포판（x86_64 / aarch64） | Ubuntu 20.04+ / Debian 11+ / CentOS 7+ |
| CPU | 1코어 | 2코어 |
| 메모리 | 512 MB | 1 GB+ |
| 디스크 | 200 MB（바이너리 + 데이터） | 1 GB+（로그와 SQLite 포함） |
| 네트워크 | 외부 네트워크 접근 가능（최초 다운로드） | 안정적인 내부 네트워크면 충분 |

## 아키텍처 지원

| 플랫폼 | 용도 |
|------|------|
| `linux/amd64` | 주류 x86_64 서버（프로덕션） |
| `linux/arm64` | ARM 서버（Graviton / 라즈베리 파이 / 쿤펑 / 페이텅, 프로덕션） |
| `darwin/amd64` / `darwin/arm64` | macOS 개발 머신（개발 디버깅 전용, 제공 안 함） |

## 실행 의존성

- **런타임 의존성 제로**: 프런트엔드, SQLite, 정적 리소스가 모두 바이너리에 임베드되어 PHP / Node / 데이터베이스 설치가 필요 없습니다
- Docker 관리 기능은 호스트 머신에 Docker가 설치되어 있어야 합니다（패널 자체는 Docker에 의존하지 않음）

## 권한

- 원클릭 설치 스크립트는 `root` 또는 `sudo`가 필요합니다
- 패널 프로세스는 전용 저권한 사용자（예: `opsmini`）로 실행하는 것을 권장합니다, 자세한 내용은 [systemd 호스팅](systemd.md) 참조
