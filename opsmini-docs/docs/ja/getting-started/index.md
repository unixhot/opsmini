## 主要概念

| 概念 | 説明 |
|------|------|
| **単一ホストパネル** | 各ホストが独立して 1 つの OpsMini インスタンスを実行し、中央ノードに依存しない |
| **単一バイナリ配布** | フロントエンド UI は `go:embed` で埋め込み。デプロイは実行ファイル 1 つのコピーだけ |
| **デュアル API** | `/api/v1` はブラウザ UI 向け（JWT + RBAC）、`/agent/v1` はマシン/サードパーティ連携向け（Token + コマンドホワイトリスト） |
| **AI 大規模モデル運用** | 自然言語による診断、ログ分析、コマンド実行。OpenAI / DeepSeek / Qwen / Ollama に接続 |
