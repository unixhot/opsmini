# การจัดการแอปพลิเคชัน

การจัดการแอปพลิเคชันครอบคลุมทรัพยากรสี่ประเภทอย่างเป็นเอกภาพ ได้แก่ เว็บไซต์ ฐานข้อมูล คอนเทนเนอร์ และร้านซอฟต์แวร์

## เว็บไซต์

- สร้าง / จัดการไซต์ Nginx และไซต์ static
- กำหนดค่าโดเมน สภาพแวดล้อมรันไทม์ (PHP / Node / static) การออกและต่ออายุใบรับรอง SSL
- การเปิด/หยุดไซต์และการดูสถานะ

## ฐานข้อมูล

- สร้าง / จัดการอินสแตนซ์ฐานข้อมูล MySQL, PostgreSQL
- ดูรายการฐานข้อมูล ชุดอักขระ และการกำหนดค่าอื่น ๆ

## คอนเทนเนอร์ (Docker)

- **คอนเทนเนอร์**: รายการ เริ่ม หยุด รีสตาร์ท ลบ
- **อิมเมจ**: ดูและลบอิมเมจ
- **วอลุ่ม**: ดูและลบวอลุ่ม
- **เน็ตเวิร์ก**: ดูและลบเน็ตเวิร์ก

> การจัดการ Docker ต้องติดตั้ง Docker บนโฮสต์และกำหนดค่า `DOCKER_HOST` แล้ว; หากการเริ่มต้นไคลเอนต์ Docker ล้มเหลว พาเนลจะลดระดับการทำงานอย่างสง่างามและซ่อนเส้นทางคอนเทนเนอร์

## ร้านซอฟต์แวร์

- มีหมวดหมู่แอปพลิเคชันที่พบบ่อยในตัว (บริการเว็บ ฐานข้อมูล แคช การมอนิเตอร์ ฯลฯ)
- แอปพลิเคชันติดตั้ง / ถอนการติดตั้ง / เริ่ม / หยุด / รีสตาร์ทได้ในคลิกเดียว (Docker Shell script)
- รองรับการนำเข้าเทมเพลตแอปพลิเคชันที่กำหนดเองและการซิงค์เทมเพลตทางการ
