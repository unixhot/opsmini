# AI 어시스턴트

OpsMini는 AI 대형 모델 운영 능력을 내장하여 자연어로 시스템 진단, 로그 분석, 명령 실행을 수행합니다.

## 기능

- **자연어 진단**: 장애 현상을 설명하면 AI가 실시간 시스템 상태와 결합하여 진단 제안을 제공합니다
- **로그 분석**: AI가 이상 로그를 분석하고 오류의 근본 원인을 찾아냅니다
- **명령 실행**: AI가 자연어 의도를 운영 명령으로 변환하고, 권한 확인 후 실행합니다
- **심층 사고**: 복잡한 추론 문제를 해결하기 위한「먼저 생각하고 답하기」모드 선택 가능
- **내장 도구**: 호스트 시스템 정보（CPU/메모리/디스크/프로세스/포트/방화벽）를 실시간 주입하고, 함수 호출을 통해 SkillHub에서 스킬 검색·설치를 지원합니다

## 지원 LLM 제공자

| Provider | 설명 |
|----------|------|
| `openai` | OpenAI 호환 인터페이스 |
| `deepseek` | DeepSeek |
| `qwen` | 통의천문（DashScope 호환 인터페이스） |
| `ollama` | 로컬 Ollama 배포 |

## 설정

**패널「설정 → AI 대형 모델 연동」**에서 통합 설정합니다（기존 `config.yaml`의 `ai` 섹션은 이곳으로 이전되었으며 런타임 즉시 적용）:

- AI 어시스턴트 활성화（총 스위치）
- 모델 제공자 / 모델명 / API Key / API 주소
- 자연어 실행 작업 / 로그 지능형 분석 / 알림 지능형 진단 스위치

> 설정 우선순위: 환경 변수 `OPSMINI_AI_KEY` > 패널 설정 > 설정 파일에 잔존하는 `ai.*`. 키를 디스크에 저장하지 않도록 환경 변수에 저장하는 것을 권장합니다. 자세한 내용은 [패널 설정](../configuration/panel-settings.md#ai-config)을 참조하세요.

## 보안 메커니즘

- AI가「실행 의도」로 판단하면 구조화된 action + 파라미터를 생성합니다
- 권한 화이트리스트에 부합할 때만 실행; 미허가 / 고위험 작업은 사용자 2차 확인을 요구합니다
- 실행 동작은 감사 로그에 기록됩니다
- 「AI 어시스턴트 활성화」스위치를 끄면 AI 관련 인터페이스가 바로 거부됩니다

## MCP 관리

MCP（Model Context Protocol）서비스 설정을 지원하여 AI 어시스턴트의 능력과 데이터 소스를 확장합니다. 「AI 어시스턴트 → MCP」에서 MCP 설정을 추가·조회·수정·삭제할 수 있으며, 명령（stdio）과 URL（SSE/HTTP）두 가지 전송 방식을 지원합니다.

## 스킬（Skill Hub）

내장된「스킬」탭으로 SkillHub 스킬 마켓과 연동합니다:

- 스킬 검색, 원클릭 설치
- 로컬 스킬 업로드, 수동 스킬 생성
- 설치된 스킬 활성화/비활성화, 삭제
