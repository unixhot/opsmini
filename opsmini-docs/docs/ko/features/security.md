# 호스트 보안

OpsMini는 호스트 보안 센터를 내장하여 다섯 가지 보안 능력을 제공합니다.

## 보안 개요

보안 센터 홈은 전체 보안 태세를 집계하여 표시하며, 베이스라인 규정 준수율, 파일 변경, 위협 발견, 방화벽 상태, 로그인 보안 등을 포함합니다.

## 베이스라인 검사

- 호스트에 대해 보안 베이스라인 스캔 수행（예: 비밀번호 정책, SSH 설정, 시스템 강화 항목）
- 최근 스캔 결과와 미준수 항목 조회
- 원클릭 스캔 시작

## 파일 무결성 모니터링（FIM）

- 주요 파일 / 디렉터리에 대해 베이스라인 구축
- 파일의 추가·삭제·변경 변화를 감지하고 이벤트 기록
- 베이스라인 재구축, 변경 이벤트 조회 지원

## 위협 탐지

- 호스트 위협 스캔（이상 프로세스, 의심 파일 등）
- 위협 발견 목록 조회
- 위협을 처리 완료로 표시

## 방화벽

- 방화벽 상태 조회
- 방화벽 켜기 / 끄기
- 포트 허용 / 거부, 규칙 삭제

## 로그인 보안

- 로그인 행위 분석（성공 / 실패, 출처 IP）
- SSH 로그인 기록 조회
- 로그인 실패 속도 제한과 잠금 연동

## 관련 권한 포인트

보안 작업은 RBAC 권한 포인트의 제어를 받습니다: `security.scan`、`security.firewall`、`security.fim`、`security.threat`.
