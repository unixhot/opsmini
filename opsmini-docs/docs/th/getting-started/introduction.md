# แนะนำผลิตภัณฑ์

OpsMini เป็นพาเนลปฏิบัติการโฮสต์ Linux น้ำหนักเบา (เทียบเคียง Baota / 1Panel) โดยมีความแตกต่างหลักคือการปฏิบัติการด้วยโมเดล AI ในตัวและ REST API มาตรฐานภายนอก

## ตำแหน่ง

| มิติ | คำอธิบาย |
|------|------|
| สถานการณ์เป้าหมาย | เซิร์ฟเวอร์ Linux เครื่องเดียว (เครื่องเล็ก 1C1G ก็รันได้) |
| แนวคิดหลัก | ติดตั้งหนึ่งเครื่อง จัดการหนึ่งเครื่อง น้ำหนักเบา เน้นเครื่องเดียว ผสานรวมได้ |
| ความแตกต่าง | การปฏิบัติการด้วยโมเดล AI + REST API มาตรฐาน |

## ฟีเจอร์หลัก

- **การปฏิบัติการด้วยโมเดล AI**: วินิจฉัยปัญหาด้วยภาษาธรรมชาติ วิเคราะห์ล็อก รันคำสั่งปฏิบัติการ เชื่อมต่อ OpenAI / DeepSeek / Qwen / Ollama
- **REST API มาตรฐาน**: `/api/v1` (UI เบราว์เซอร์) และ `/agent/v1` (เครื่องต่อเครื่อง) สำหรับแพลตฟอร์มมอนิเตอร์ สคริปต์อัตโนมัติ เครื่องมือออร์เคสเตรชันเพื่อผสานรวม
- **การจัดการ Docker**: ทรัพยากรสี่ประเภท คอนเทนเนอร์ อิมเมจ วอลุ่ม เน็ตเวิร์ก
- **เว็บเทอร์มินัล**: เทอร์มินัลโต้ตอบคล้าย SSH ด้วย WebSocket + pty
- **ความปลอดภัยของโฮสต์**: การตรวจสอบ baseline การมอนิเตอร์ความสมบูรณ์ของไฟล์ (FIM) การตรวจจับภัยคุกคาม ไฟร์วอลล์ ความปลอดภัยการล็อกอิน
- **i18n 7 ภาษา**: จีนตัวย่อ/ตัวเต็ม อังกฤษ ญี่ปุ่น เกาหลี ไทย เยอรมัน
- **ส่งมอบไบนารีเดียว**: frontend ฝังผ่าน `go:embed` ไม่มีไลบรารีรันไทม์

## เทคโนโลยีที่ใช้

Go 1.25 · Gin · GORM · SQLite (Go ล้วน) · Vue 3 · ECharts

## ความแตกต่างจากผลิตภัณฑ์ที่คล้ายกัน

| ความสามารถ | Baota / 1Panel | OpsMini |
|------|--------------|---------|
| วิธีการปฏิบัติการ | ใช้งานด้วยกราฟิก | กราฟิก + การปฏิบัติการด้วยภาษาธรรมชาติของ AI |
| การผสานรวมภายนอก | ไม่มี API มาตรฐาน | REST API มาตรฐาน (`/agent/v1`) |
| การผสานรวมมอนิเตอร์ | ต้องติดตั้ง node_exporter เพิ่ม | `/metrics` ในตัว (เข้ากันได้กับ node_exporter) |
| รูปแบบการส่งมอบ | สคริปต์ติดตั้ง + หลายคอมโพเนนต์ | ไบนารีเดียว static link |
