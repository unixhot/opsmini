## Web 終端

- 基於 WebSocket + pty 的類 SSH 互動終端
- 僅對 operator 及以上角色開放，會話記錄審計

```text
前端 ws://host/api/v1/terminal?token=...
  → 服务端校验 token + 角色
  → 启动 pty → 双向数据转发
  → 关闭时回收 pty、记录会话时长
```

## 計劃任務

三類任務：

| 型別 | 說明 | 操作 |
|------|------|------|
| 面板任務 | 由面板常駐排程（robfig/cron） | 增刪改查 |
| 系統任務 | `/etc/crontab`、`/etc/cron.d/` | 只讀展示 + 受控編輯 |
| 使用者任務 | `/var/spool/cron/<user>` | 只讀展示 + 受控編輯 |
