# 更新日誌

各版本變更記錄。

## v1.2.1（2026-10-27）

**修正：移除 4 個跨邊界實作的多機 AI 工具**

v1.2.0 註冊了 `list_remote_hosts` / `remote_exec` / `remote_pull_file` / `remote_push_file` 四個多機工具，讓面板的 AI 透過 OpsMini Server 的控制面 HTTP 介面（4508）向其它納管主機派送命令與檔案。這個實作跨越了架構邊界，現已移除：

- 4508 是 OpsMini Server 提供給 OpsAnt 的**內部**介面，定位「僅本機 / 內網」，且不校驗權杖；
- 面板在多機鏈路中的角色是**被納管的 Agent**，只應透過 4507 的 gRPC 長連線與 Server 通訊（註冊、心跳、接收任務），不應反向呼叫控制面；
- 若要讓這個設計可用，就必須把 4508 對外開放 —— 等於掛出一個無認證的遠端命令執行入口。

工具集因此回到 **29 個**（16 唯讀 / 5 低風險寫入 / 8 高風險寫入）。多機編排與多機 AI 由 OpsAnt 承擔，它已有統一的執行 API（`/api/opsant/v1/tasks/run-shell/`、`tasks/run-script/`、`tasks/send-file/`、`tasks/get-minion-file/` 等）以及 salt / ansible / opsmini 三個執行引擎。

**升級無需遷移**：這 4 個工具在舊版本中依賴 4508 可達，實際上一直不可用。

## v1.2.0（2026-10-27）

**AI 智慧體（從「維運顧問」到「維運操作員」）**

- **自研輕量 ReAct 核心**：Reason → Act → Observe 閉環，不引入任何 Agent 框架，維持單一二進位與零 CGO；單輪預設 12 步上限，超過即停止呼叫工具並回報已知資訊
- **33 個內建工具**：唯讀 16 個（系統概觀 / 程序 / 連接埠 / 磁碟 / 目錄佔用 / 日誌檢索 / 服務 / 容器 / 安全等）、低風險寫入 5 個、高風險寫入 8 個，另有 4 個多機工具依 Agent 設定動態註冊
- **串流工具呼叫**：依 index 累積拼接 tool_calls 片段；對不支援串流工具呼叫的廠商自動降級為非串流重試
- **思考鏈視覺化**：前端逐步顯示「呼叫了什麼工具、帶了什麼參數、取得什麼原始輸出」，結論可稽核

**分級授權與人機協同**

- **四級風險模型**：L0 唯讀自主執行 / L1 低風險預設需確認（可依工具開放免確認）/ L2 高風險每次必確認且禁止免確認 / L3 災難性操作以正規表達式硬禁止
- **L3 於執行前攔截**：`rm -rf /`、`mkfs`、`dd of=/dev/sd*`、fork 炸彈、清空防火牆、覆寫 `/etc/passwd` 等，即使管理員核准也不會執行；另加兩條面板自我保護（禁止更動資料目錄、禁止關閉面板監聽埠）
- **中斷—恢復**：高風險呼叫會暫存並掛起，使用者在對話中核准或拒絕後，自 SQLite 恢復訊息序列繼續執行；拒絕路徑經實測確認無副作用

**雙向 MCP**

- **MCP 用戶端**：基於 MCP 官方 Go SDK，支援 stdio 與 Streamable HTTP 兩種傳輸，外部 MCP 服務的工具以 `mcp__<服務名>__<工具名>` 自動接入，每 2 分鐘對帳設定
- **MCP 伺服端**：將自身工具集發佈到 `/mcp`，以 Bearer 權杖驗證，預設僅下發 L0/L1 工具（L2 不對未授權用戶端暴露，因外部用戶端無法呈現面板確認視窗）

**排程 AI 任務**

- **計畫任務新增第四種類型「Agent 任務」**：填一段提示詞即可依 cron 自動執行，排程、啟停、上次執行時間、失敗告警全部沿用既有機制
- **無人值守授權降級**：排程執行時無人在旁按下「核准」，因此命中 L2 的工具直接拒絕並將原因回灌給模型，模型改用唯讀工具繼續完成，報告中註明「該操作需人工執行」並提供可複製的指令
- **可靠性與成本控制**：任務層級的步數上限與總逾時雙重限流；連續失敗 3 次自動停用任務，避免「每天失敗每天告警」；面板儲存即歸零失敗次數
- **內建 5 個巡檢預設**：主機巡檢 / 安全巡檢 / 磁碟空間 / 服務狀態 / 日誌異常，另有 4 個常用頻率預設

**單檔 HTML 報告**

- **報告即一個自包含 HTML 檔案**：樣式內嵌、無指令碼、無外部樣式表、無網路字型、無圖片，複製到隨身碟、當郵件附件、放靜態伺服器都能正常顯示
- **可開啟、可下載**：任務列表每列提供「開啟」（新分頁直接呈現）與「下載」兩個入口；中文檔名依 RFC 5987 編碼
- **歸檔至資料目錄**：`<資料目錄>/reports/<任務名>/` 下同時寫入 `.html` 與 `.md`，所有生成型功能統一依功能分子目錄
- **渲染安全**：報告正文混有主機資料（日誌片段、程序命令列、設定值），渲染器先整體 HTML 轉義再套用行內規則，僅放行 http/https/mailto 連結，日誌中的 `<script>` 只會顯示為文字；回應另附嚴格 CSP
- **需要 PDF 時**：於報告頁使用瀏覽器「列印 → 另存為 PDF」，樣式表已含列印規則

**通知與稽核**

- **共用通知器**：將原告警的通知分發抽成統一 `Notifier`（面板 / 郵件 / 企業微信 / 釘釘 / 飛書），AI 任務與告警行為完全一致；管道為空時預設發站內通知
- **稽核留痕**：AI 工具呼叫寫入稽核日誌，無人值守被拒絕的操作記為 `unattended-deny`，人工拒絕記 `reject:` 前綴

**其他改進**

- 側邊欄版本號改為顯示後端真實版本（原為寫死值）
- 新增 `docs/ai-agent.md` 等 7 語言設計文件
- Agent 任務建議由管理員在「AI 助手 → 工具權限」中依需求調整各工具策略；高風險工具始終鎖定為「需確認」

## v1.1.0（2026-09-21）

**多機管理（Agent / Server 架構）**

- **Agent gRPC 客戶端**：Agent 主動連 OpsMini Server（單埠 gRPC 雙向流），心跳 + 指數退避重連，接收執行 / 檔案任務並回傳結果
- **OpsMini Server 端**：註冊 / 心跳 / 連線管理、執行任務下發、結果接收（程式碼遷至 OpsAnt 專案獨立 Go 子專案 `opsmini-server/`，OpsMini 僅保留 Agent）
- **命令 / 指令碼執行**：command 與 shell / python 指令碼，結果（stdout / stderr / exit code / 耗時）回傳
- **檔案拉取（PullFile）**：Server 從 Agent 拉取檔案（分片上傳 + size / md5 校驗）
- **檔案下發（PushFile）**：Server 向 Agent 下發檔案（分片 + 斷點續傳 + md5 校驗），支援目標為目錄（保留原檔名）
- **連線狀態檢測 + 長連線保活**：Agent 線上 / 離線狀態、心跳超時判定、gRPC keepalive
- **接入 OpsAnt**：面板「設定」頁視覺化配置 OpsAnt 地址 / Token（執行時熱切換，Token 顯示支援眼睛切換明文 / 密文），SSO 免認證跳轉（預設開啟）
- **移除 `/agent/v1` REST API**：改用 gRPC 雙向流（原 REST API 及前端「API Token」設定頁一併移除）

**面板功能增強**

- **檔案頁目錄下載**：目錄一鍵壓縮為 zip 下載（彈窗提示 + 目錄大小 + 所在分割區磁碟使用率）
- **檔案頁目錄刪除**：遞迴刪除目錄（危險操作彈窗 + 輸入目錄名二次確認）
- **檔案頁長名稱最佳化**：超長檔案 / 目錄名省略顯示，懸停檢視完整名（消除橫向捲軸）
- **系統管理「網路」路由表**：網卡下方新增路由表展示（目標網路 / 閘道 / 子網掩碼 / 標誌 / 介面 / 度量）
- **MCP 配置增強**：支援「配置檔案（JSON）」與「表格」兩種輸入方式；SSE / HTTP 方式支援自訂請求頭（多個）與超時時間
- **防火牆增強**：啟用前自動放行面板埠與 SSH 埠（22），避免啟用後無法存取；識別「已安裝未啟用」的 ufw
- **Prometheus 指標增強**：新增 `opsmini_cpu_usage_percent` / `opsmini_mem_usage_percent` 即時使用率、`node_procs_total` 總處理程序數
- **統一確認彈窗**：所有刪除 / 危險操作改用平臺自帶確認彈窗（替換瀏覽器原生 confirm）

**終端最佳化**

- **輸出留白**：命令輸出左右 / 底部增加留白，不再貼邊
- **全螢幕 Esc 修復**：全螢幕模式下按 Esc 不再退出全螢幕（避免與 vim 編輯模式的 Esc 衝突）
- **會話保持**：切換頁面後終端會話不再重置（會話有效期內保持）
- **字元集設定**：新增字元集選擇（UTF-8 / GBK / GB18030 / Big5），解決中文亂碼

**體驗最佳化**

- **頁面標題**：顯示「OpsMini · 存取地址」，多標籤頁可區分
- **密碼可見性**：修改密碼、接入 OpsAnt Token 等輸入框新增「顯示 / 隱藏」小眼睛
- **設定頁佈局**：「雙因素驗證」與「接入 OpsAnt」並排展示，移除「自動更新」開關

## v1.0.0（2026-09-13）

OpsMini 首個正式版本，單二進位制交付，核心能力：

- **AI 維運**：自然語言診斷、日誌智慧分析、命令生成與執行（SSE 流式輸出）、MCP 工具接入
- **監控告警**：CPU / 記憶體 / 磁碟 / 網路指標時序採集，告警規則支援郵件、面板、企業微信、釘釘、飛書群機器人通知
- **主機安全**：安全評分、基線檢查、檔案完整性監控（FIM）、威脅檢測、防火牆、登入安全
- **軟體商店**：應用分類 + 一鍵安裝 + 官方模版同步
- **AI 技能（Skill Hub）**：技能檢索、安裝、上傳
- **Web 終端**：WebSocket + pty 互動式 shell，多會話
- **常規維運**：網站、資料庫、計劃任務、檔案管理
- **雙因素驗證（2FA）**：全域性開關 + 每使用者 TOTP 繫結
- **監控匯出**：Prometheus `/metrics` 端點（node_exporter 相容）
- **通知管理**：SMTP / 企業微信 / 釘釘 / 飛書
- **配置精簡**：JWT 金鑰、Agent Token、AI 配置均面板化，配置檔案僅保留最小項
- **日誌系統**：日誌級別可配置（info / warn / error），日誌落盤
- **賬號恢復**：`-reset-pass` / `-reset-mfa` 子命令
- **7 語言 i18n**：簡中 / 繁中 / 英 / 日 / 韓 / 泰 / 德
- **白色極簡 UI**：白色 + 黑色字型配色，品牌藍點綴
- **雙 API**：`/api/v1`（瀏覽器用）+ `/agent/v1`（機器間標準 REST）
