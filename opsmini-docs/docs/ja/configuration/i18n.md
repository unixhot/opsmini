# パネルの多言語対応

OpsMini パネルには 7 言語の UI が内蔵されており、追加設定なしで切り替えられます。

## 対応言語

| 言語 | コード |
|------|------|
| 簡体字中国語 | zh |
| 繁體中文 | zh-TW |
| English | en |
| 日本語 | ja |
| 한국어 | ko |
| ไทย | th |
| Deutsch | de |

## 切り替え方法

1. パネルにログイン後、トップバー右側の言語セレクターをクリック
2. 目的の言語を選択すると、UI が即座に切り替わります

> 言語設定は現在のセッションにのみ有効で、他のユーザーには影響しません。

## 実装メモ

- フロントエンドの言語パックは Vue 3 SPA にインラインで含まれ、`/api/v1/i18n/{lang}` でも必要に応じて取得できます
- 7 言語すべてが単一バイナリに内蔵されており、追加ダウンロードは不要です
