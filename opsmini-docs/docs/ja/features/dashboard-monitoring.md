# ダッシュボードと監視

OpsMini には指標収集と監視アラートの機能が内蔵されており、監視コンポーネントを別途インストールする必要はありません。

## ダッシュボード

ログイン後のデフォルトでダッシュボードが表示され、以下を確認できます：

- **リソース概要**：CPU 使用率、メモリ使用量、ロード、ディスク、ネットワークトラフィック
- **リアルタイム時系列**：CPU / メモリ / ディスク / ネットワークの時間変化曲線（ECharts 描画）
- **システム状態**：稼働時間、ホスト情報

指標コレクタは 10 秒ごとにサンプリングし、メモリのリングバッファで 24 時間保持、履歴データはダウンサンプリングして SQLite に保存します（1 分粒度で 7 日保持）。

## 監視

監視ページでは以下を提供します：

- **時系列クエリ**：時間範囲を指定して履歴指標を確認
- **アラートルール**：CPU / メモリ / ディスク / サービスなどの指標のアラート閾値と継続時間をカスタマイズ
- **アラートイベント**：発火済みのアラートイベントと状態を確認

### アラートルールの例

| フィールド | 説明 |
|------|------|
| 名前 | ルール名。例：「CPU が継続的に高負荷」 |
| 指標 | `cpu` / `mem` / `disk` / `service` |
| 条件 | 例：`>90%` |
| 継続時間 | 発火までに条件を満たし続ける必要がある時間 |
| 通知方法 | 関連付けられた通知チャネル |

## 通知

アラート発火後は通知センターから管理者にプッシュできます。パネル内通知と既読管理に対応しています。

## Prometheus 連携

パネルには node_exporter 互換の `/metrics` エンドポイントが内蔵されており、Prometheus が直接スクレイプできます。詳しくは [Prometheus 指標](../api/prometheus.md) を参照してください。
