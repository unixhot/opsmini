# 更新履歴

各バージョンの変更記録。

## v1.1.0（2026-09-21）

**マルチホスト管理（Agent / Server アーキテクチャ）**

- **Agent gRPC クライアント**：Agent が OpsMini Server へ自律的に接続（単一ポートの gRPC 双方向ストリーム）。ハートビート + 指数バックオフによる再接続、実行 / ファイルタスクの受信と結果の返送
- **OpsMini Server 側**：登録 / ハートビート / 接続管理、実行タスクの配信、結果の受信（コードは OpsAnt プロジェクト配下の独立した Go サブプロジェクト `opsmini-server/` へ移行。OpsMini 側は Agent のみを保持）
- **コマンド / スクリプト実行**：command および shell / python スクリプトに対応。結果（stdout / stderr / exit code / 所要時間）を返送
- **ファイル取得（PullFile）**：Server が Agent からファイルを取得（チャンク分割アップロード + size / md5 による検証）
- **ファイル配信（PushFile）**：Server から Agent へファイルを配信（チャンク分割 + レジューム転送 + md5 による検証）。配信先がディレクトリの場合も対応（元のファイル名を保持）
- **接続状態の検出 + 長時間接続のキープアライブ**：Agent のオンライン / オフライン状態、ハートビートタイムアウトの判定、gRPC keepalive
- **OpsAnt 連携**：パネルの「設定」ページで OpsAnt のアドレス / Token を視覚的に設定（実行時のホットスイッチに対応、Token 表示は目アイコンでプレーンテキスト / マスク表示を切り替え可能）、SSO による認証スキップのリダイレクト（デフォルトで有効）
- **`/agent/v1` REST API の削除**：gRPC 双方向ストリームへ移行（従来の REST API およびフロントエンドの「API Token」設定ページも併せて削除）

**パネル機能の強化**

- **ファイルページのディレクトリダウンロード**：ディレクトリをワンクリックで zip に圧縮してダウンロード（ダイアログ通知 + ディレクトリサイズ + 配置先パーティションのディスク使用率を表示）
- **ファイルページのディレクトリ削除**：ディレクトリの再帰的削除（危険操作のダイアログ + ディレクトリ名を入力させる二次確認）
- **ファイルページの長い名称の最適化**：長すぎるファイル / ディレクトリ名は省略表示し、ホバーで完全な名称を確認可能（横スクロールバーを解消）
- **システム管理の「ネットワーク」ルーティングテーブル**：NIC の配下にルーティングテーブルを追加表示（宛先ネットワーク / ゲートウェイ / サブネットマスク / フラグ / インターフェース / メトリック）
- **MCP 設定の強化**：「設定ファイル（JSON）」と「テーブル」の 2 種類の入力方法に対応。SSE / HTTP 方式ではカスタムリクエストヘッダー（複数）とタイムアウト時間を設定可能
- **ファイアウォールの強化**：有効化前にパネルポートと SSH ポート（22）を自動で許可し、有効化後にアクセスできなくなる問題を回避。「インストール済みだが未使用」の ufw を識別
- **Prometheus 指標の強化**：即時使用率 `opsmini_cpu_usage_percent` / `opsmini_mem_usage_percent`、総プロセス数 `node_procs_total` を追加
- **確認ダイアログの統一**：すべての削除 / 危険操作をプラットフォーム標準の確認ダイアログに変更（ブラウザネイティブの confirm を置き換え）

**ターミナルの最適化**

- **出力の余白**：コマンド出力の左右 / 下部に余白を追加し、端に密着しないように改善
- **全画面での Esc の修正**：全画面モードで Esc を押しても全画面を終了しないように修正（vim の編集モードにおける Esc との競合を回避）
- **セッションの維持**：ページを切り替えてもターミナルセッションがリセットされないように改善（セッションの有効期限内は維持）
- **文字セット設定**：文字セットの選択を追加（UTF-8 / GBK / GB18030 / Big5）。中国語の文字化けを解消

**ユーザー体験の向上**

- **ページタイトル**：「OpsMini · アクセスアドレス」を表示し、複数タブを区別しやすく改善
- **パスワードの可視性**：パスワード変更、OpsAnt 連携 Token などの入力欄に「表示 / 非表示」の目アイコンを追加
- **設定ページのレイアウト**：「二要素認証」と「OpsAnt 連携」を横並びで表示し、「自動更新」スイッチを削除

## v1.0.0（2026-09-13）

OpsMini の最初の正式バージョン。単一バイナリで配布。主要機能：

- **AI 運用**：自然言語による診断、ログのインテリジェント分析、コマンド生成と実行（SSE ストリーミング出力）、MCP ツール連携
- **監視アラート**：CPU / メモリ / ディスク / ネットワーク指標の時系列収集。アラートルールはメール、パネル、WeCom（企業微信）、DingTalk（钉钉）、Feishu（飛書）のグループボット通知に対応
- **ホストセキュリティ**：セキュリティスコア、ベースライン検査、ファイル整合性監視（FIM）、脅威検出、ファイアウォール、ログインセキュリティ
- **アプリストア**：アプリの分類 + ワンクリックインストール + 公式テンプレート同期
- **AI スキル（Skill Hub）**：スキルの検索、インストール、アップロード
- **Web ターミナル**：WebSocket + pty の対話型シェル、マルチセッション
- **通常の運用**：ウェブサイト、データベース、スケジュールタスク、ファイル管理
- **二要素認証（2FA）**：グローバルスイッチ + ユーザーごとの TOTP バインディング
- **監視エクスポート**：Prometheus `/metrics` エンドポイント（node_exporter 互換）
- **通知管理**：SMTP / WeCom（企業微信）/ DingTalk（钉钉）/ Feishu（飛書）
- **設定の簡素化**：JWT シークレット、Agent Token、AI 設定をすべてパネル化し、設定ファイルには最小限の項目のみを保持
- **ログシステム**：ログレベルを設定可能（info / warn / error）、ログをディスクに保存
- **アカウント復旧**：`-reset-pass` / `-reset-mfa` サブコマンド
- **7 言語 i18n**：簡体字中国語 / 繁体字中国語 / 英語 / 日本語 / 韓国語 / タイ語 / ドイツ語
- **ホワイトミニマル UI**：白 + 黒フォントの配色、ブランドブルーのアクセント
- **デュアル API**：`/api/v1`（ブラウザ用）+ `/agent/v1`（マシン間の標準 REST）
