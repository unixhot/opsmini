# 更新日志

各版本变更记录。

## v1.2.0（2026-10-27）

**AI 智能体（从「运维顾问」到「运维操作员」）**

- **自研轻量 ReAct 内核**：Reason → Act → Observe 闭环，不引入任何 Agent 框架，保持单二进制与零 CGO；默认单轮 12 步上限，超限即停止调用工具并汇报已知信息
- **33 个内置工具**：只读 16 个（系统概览 / 进程 / 端口 / 磁盘 / 目录占用 / 日志检索 / 服务 / 容器 / 安全等）、低危写 5 个、高危写 8 个，另有 4 个多机工具按 Agent 配置动态注册
- **流式工具调用**：按 index 累积拼接 tool_calls 碎片；对不支持流式工具调用的厂商自动降级为非流式重试
- **思考链可视化**：前端逐步展示「调用了什么工具、传了什么参数、拿到什么原始输出」，结论可审计

**分级授权与人机协同**

- **四级风险模型**：L0 只读自主执行 / L1 低危默认需确认（可按工具开放免确认）/ L2 高危每次必确认且禁止免确认 / L3 灾难性操作正则硬禁止
- **L3 硬禁止在执行前拦截**：`rm -rf /`、`mkfs`、`dd of=/dev/sd*`、fork 炸弹、清空防火墙、覆盖 `/etc/passwd` 等，即使管理员批准也不会执行；另加两条面板自保护（禁止动数据目录、禁止关闭面板监听端口）
- **中断—恢复**：高危调用挂起并落库，用户在对话里批准或拒绝后从 SQLite 恢复消息序列继续执行；拒绝路径经实测确认无副作用

**双向 MCP**

- **MCP 客户端**：基于 MCP 官方 Go SDK，支持 stdio 与 Streamable HTTP 两种传输，外部 MCP 服务的工具以 `mcp__<服务名>__<工具名>` 自动接入，每 2 分钟对账配置
- **MCP 服务端**：把自身工具集发布到 `/mcp`，Bearer 令牌鉴权，默认只下发 L0/L1 工具（L2 不对未授权客户端暴露，因外部客户端无法呈现面板确认弹窗）

**定时 AI 任务**

- **计划任务新增第四种类型「Agent 任务」**：填一段提示词即可按 cron 自动执行，调度、启停、上次执行时间、失败告警全部复用既有机制
- **无人值守授权降级**：定时运行没有人在旁点「批准」，因此命中 L2 的工具直接拒绝并把原因回灌给模型，模型改用只读工具继续完成，报告里写明「该操作需人工执行」并给出可复制命令
- **可靠性与成本控制**：任务级步数上限与总超时双限流；连续失败 3 次自动停用任务，避免「每天失败每天告警」；面板保存即清零失败计数
- **内置 5 个巡检预设**：主机巡检 / 安全巡检 / 磁盘空间 / 服务状态 / 日志异常，另有 4 个常用频率预设

**单文件 HTML 报告**

- **报告即一个自包含 HTML 文件**：样式内联、无脚本、无外部样式表、无网络字体、无图片，拷到 U 盘、当邮件附件、放静态服务器都能正常显示
- **可打开、可下载**：任务列表每行提供「打开」（新标签页直接渲染）与「下载」两个入口；中文文件名按 RFC 5987 编码
- **归档到数据目录**：`<数据目录>/reports/<任务名>/` 下同时落 `.html` 与 `.md`，所有生成型功能统一按功能分子目录
- **渲染安全**：报告正文混有主机数据（日志片段、进程命令行、配置值），渲染器先整体 HTML 转义再套行内规则，只放行 http/https/mailto 链接，日志里的 `<script>` 只会显示为文本；响应另附严格 CSP
- **需要 PDF 时**：在报告页用浏览器「打印 → 另存为 PDF」，样式表已带打印规则

**通知与审计**

- **共享通知器**：把原告警里的通知分发抽成统一 `Notifier`（面板 / 邮件 / 企业微信 / 钉钉 / 飞书），AI 任务与告警行为完全一致；渠道为空时默认发站内通知
- **审计留痕**：AI 工具调用写入审计日志，无人值守被拒的操作记 `unattended-deny`，人工拒绝记 `reject:` 前缀

**其他改进**

- 侧边栏版本号改为显示后端真实版本（原为写死值）
- 新增 `docs/ai-agent.md` 等 7 语言设计文档
- Agent 任务建议由管理员在「AI 助手 → 工具权限」中按需调整各工具策略；高危工具始终锁定为「需确认」

## v1.1.0（2026-09-21）

**多机管理（Agent / Server 架构）**

- **Agent gRPC 客户端**：Agent 主动连 OpsMini Server（单端口 gRPC 双向流），心跳 + 指数退避重连，接收执行 / 文件任务并回传结果
- **OpsMini Server 端**：注册 / 心跳 / 连接管理、执行任务下发、结果接收（代码迁至 OpsAnt 项目独立 Go 子项目 `opsmini-server/`，OpsMini 仅保留 Agent）
- **命令 / 脚本执行**：command 与 shell / python 脚本，结果（stdout / stderr / exit code / 耗时）回传
- **文件拉取（PullFile）**：Server 从 Agent 拉取文件（分片上传 + size / md5 校验）
- **文件下发（PushFile）**：Server 向 Agent 下发文件（分片 + 断点续传 + md5 校验），支持目标为目录（保留原文件名）
- **连接状态检测 + 长连接保活**：Agent 在线 / 离线状态、心跳超时判定、gRPC keepalive
- **接入 OpsAnt**：面板「设置」页可视化配置 OpsAnt 地址 / Token（运行时热切换，Token 显示支持眼睛切换明文 / 密文），SSO 免认证跳转（默认开启）
- **移除 `/agent/v1` REST API**：改用 gRPC 双向流（原 REST API 及前端「API Token」设置页一并移除）

**面板功能增强**

- **文件页目录下载**：目录一键压缩为 zip 下载（弹窗提示 + 目录大小 + 所在分区磁盘使用率）
- **文件页目录删除**：递归删除目录（危险操作弹窗 + 输入目录名二次确认）
- **文件页长名称优化**：超长文件 / 目录名省略显示，悬停查看完整名（消除横向滚动条）
- **系统管理「网络」路由表**：网卡下方新增路由表展示（目标网络 / 网关 / 子网掩码 / 标志 / 接口 / 度量）
- **MCP 配置增强**：支持「配置文件（JSON）」与「表格」两种输入方式；SSE / HTTP 方式支持自定义请求头（多个）与超时时间
- **防火墙增强**：启用前自动放行面板端口与 SSH 端口（22），避免启用后无法访问；识别「已安装未启用」的 ufw
- **Prometheus 指标增强**：新增 `opsmini_cpu_usage_percent` / `opsmini_mem_usage_percent` 即时使用率、`node_procs_total` 总进程数
- **统一确认弹窗**：所有删除 / 危险操作改用平台自带确认弹窗（替换浏览器原生 confirm）

**终端优化**

- **输出留白**：命令输出左右 / 底部增加留白，不再贴边
- **全屏 Esc 修复**：全屏模式下按 Esc 不再退出全屏（避免与 vim 编辑模式的 Esc 冲突）
- **会话保持**：切换页面后终端会话不再重置（会话有效期内保持）
- **字符集设置**：新增字符集选择（UTF-8 / GBK / GB18030 / Big5），解决中文乱码

**体验优化**

- **页面标题**：显示「OpsMini · 访问地址」，多标签页可区分
- **密码可见性**：修改密码、接入 OpsAnt Token 等输入框新增「显示 / 隐藏」小眼睛
- **设置页布局**：「双因素验证」与「接入 OpsAnt」并排展示，移除「自动更新」开关

## v1.0.0（2026-09-13）

OpsMini 首个正式版本，单二进制交付，核心能力：

- **AI 运维**：自然语言诊断、日志智能分析、命令生成与执行（SSE 流式输出）、MCP 工具接入
- **监控告警**：CPU / 内存 / 磁盘 / 网络指标时序采集，告警规则支持邮件、面板、企业微信、钉钉、飞书群机器人通知
- **主机安全**：安全评分、基线检查、文件完整性监控（FIM）、威胁检测、防火墙、登录安全
- **软件商店**：应用分类 + 一键安装 + 官方模版同步
- **AI 技能（Skill Hub）**：技能检索、安装、上传
- **Web 终端**：WebSocket + pty 交互式 shell，多会话
- **常规运维**：网站、数据库、计划任务、文件管理
- **双因素验证（2FA）**：全局开关 + 每用户 TOTP 绑定
- **监控导出**：Prometheus `/metrics` 端点（node_exporter 兼容）
- **通知管理**：SMTP / 企业微信 / 钉钉 / 飞书
- **配置精简**：JWT 密钥、Agent Token、AI 配置均面板化，配置文件仅保留最小项
- **日志系统**：日志级别可配置（info / warn / error），日志落盘
- **账号恢复**：`-reset-pass` / `-reset-mfa` 子命令
- **7 语言 i18n**：简中 / 繁中 / 英 / 日 / 韩 / 泰 / 德
- **白色极简 UI**：白色 + 黑色字体配色，品牌蓝点缀
- **双 API**：`/api/v1`（浏览器用）+ `/agent/v1`（机器间标准 REST）
