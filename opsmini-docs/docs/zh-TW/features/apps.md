# 應用管理

應用管理統一承載網站、資料庫、容器與軟體商店四類資源。

## 網站

- 建立 / 管理 Nginx 站點與靜態站點
- 配置域名、執行環境（PHP / Node / 靜態）、SSL 證書籤發與續期
- 站點啟停與狀態檢視

## 資料庫

- 建立 / 管理 MySQL、PostgreSQL 資料庫例項
- 檢視資料庫列表、字符集等配置

## 容器（Docker）

- **容器**：列表、啟動、停止、重啟、刪除
- **映象**：檢視與刪除映象
- **磁碟區**：檢視與刪除磁碟區
- **網路**：檢視與刪除網路

> Docker 管理需要宿主機已安裝 Docker 並配置好 `DOCKER_HOST`；若 Docker 客戶端初始化失敗，面板會優雅降級並隱藏容器路由。

## 軟體商店

- 內建常用應用分類（Web 服務、資料庫、快取、監控等）
- 應用一鍵安裝 / 解除安裝 / 啟動 / 停止 / 重啟（Docker Shell 指令碼）
- 支援自定義應用模板匯入與官方模板同步
