# パネル設定

パネルの「設定」ページではランタイム設定を一元管理します。変更は即時反映され SQLite データベースに永続化されるため、設定ファイルの編集やサービスの再起動は不要です。以前は `config.yaml` に記述していた一部の設定（AI、Agent トークン、監視認証）はここに移行しています。

> 「パネル設定」へのアクセスには `settings.view` 権限、保存には `settings.edit` 権限が必要です（デフォルトでは `admin` ロールが保持）。

## 基本設定

| 項目 | 説明 |
|----|------|
| パネルポート | パネルのリッスンポート（`server.port` に対応） |
| パネルドメイン | パネルのアクセスドメイン。リンク生成とリバースプロキシのシナリオで使用 |
| セキュリティ入口 | 隠しパスプレフィックス（`server.secret_entry` に対応）。例：`/opsmini_panel`。空なら無効 |
| HTTPS を有効化 | HTTPS を有効にするか（リバースプロキシと組み合わせてエッジで TLS 終端するのを推奨） |

## 二段階認証（2FA）

- **グローバルスイッチ**：有効にすると、検証アプリをバインド済みのすべてのアカウントはログイン時に 6 桁の動的コードの入力が必要になります
- 各ユーザーは独立して TOTP 検証アプリ（Google Authenticator / 1Password / 各クラウド事業者の検証アプリ APP と互換）をバインド/解除できます
- 検証アプリを紛失した場合は、サーバーにログインして `opsmini -reset-mfa <username>` でリセットできます

詳しくは [ユーザーと権限](../features/users-rbac.md#2fa) を参照してください。

## AI 大規模モデル接続 {: #ai-config }

内蔵 AI アシスタントのモデル接続をここで一元設定します。従来の `config.yaml` の `ai` セクションを置き換えます：

| 項目 | 説明 |
|----|------|
| AI アシスタントを有効化 | マスタースイッチ。オフにすると AI 関連機能は利用できません |
| モデルプロバイダ | `openai` / `deepseek` / `qwen` / `ollama` |
| モデル | モデル名。例：`gpt-4o`、`deepseek-chat`、`qwen-plus` |
| API Key | プロバイダのシークレット。空なら環境変数 `OPSMINI_AI_KEY` を読み取ります |
| API アドレス | OpenAI 互換インターフェースの Base URL。例：`https://api.openai.com/v1` |
| 自然言語での操作実行 | AI による運用操作の実行を許可するか |
| ログのインテリジェント分析 | AI ログ分析を有効にするか |
| アラートのインテリジェント診断 | AI アラート診断を有効にするか |

> 設定の優先順位：環境変数 `OPSMINI_AI_KEY` > パネル設定 > 設定ファイルに残存する `ai.*`。詳しくは [AI アシスタント](../features/ai-assistant.md) を参照してください。

## API Token

外部システム（監視プラットフォーム、自動化スクリプト、サードパーティのオーケストレーションツール）向けにアクセストークンを生成します：

- 生成したトークンは `/agent/v1` インターフェースの呼び出しに使用し、リクエストヘッダーに `Authorization: Bearer <token>` を付与します
- 空にすると Agent API は**無効化**されます
- 「ランダム生成」で強力なランダムトークンをワンクリック生成できます。保存後に有効になります
- 漏洩後は直ちに再生成する必要があります

コマンドホワイトリストは引き続き `config.yaml` の `agent.allowed_commands` で管理します。詳しくは [Agent API](../api/agent-api.md) を参照してください。

## 外観とテーマ

- **カスタムメインカラー**：パネルのブランドメインカラー（企業ブランドカラー / 個人の好み）を設定。デフォルトは OpsMini ブルー `#4f6ef7`
- **メニュー表示 / 言語**：パネル UI の言語（7 言語）とメニューの表示/非表示

## 監視エクスポート（Prometheus）

`/metrics` エンドポイント（node_exporter 互換）の認証を制御します：

| 項目 | 説明 |
|----|------|
| 認証を有効化 | `/metrics` に HTTP Basic 認証を有効にするか |
| ユーザー名 / パスワード | Basic 認証情報。ユーザー名を空にするとアクセスが開放されます |

> ここでの設定は `config.yaml` の `metrics.user/password` より優先されます。Prometheus でスクレイプする際は対応する `basic_auth` を設定する必要があります。詳しくは [Prometheus 指標](../api/prometheus.md) を参照してください。

## アプリテンプレート（アプリストア）

アプリストアのアプリテンプレートを管理します：

- **公式テンプレートの同期**：opsmini.com 公式サイトのアプリストアから公式アプリテンプレートをワンクリック同期
- **手動インポート/エクスポート**：オフライン環境では公式サイトからテンプレートをダウンロードして手動インポート、またはローカルテンプレートをエクスポートしてバックアップできます
- **データディレクトリ**：アプリデータの永続化ディレクトリ（インストールスクリプトは `DATA_DIR` 環境変数で参照）

## 通知

アラート通知チャネルを設定します：

| チャネル | 説明 |
|------|------|
| SMTP メール | SMTP サーバー / ポート / 送信元 / 宛先 / ユーザー名 / パスワード |
| WeCom（企業微信） | グループボットの Webhook アドレス |
| DingTalk（钉钉） | グループボットの Webhook アドレス |
| Feishu（飛書） | グループボットの Webhook アドレス |

アラート発火後、ここで設定したチャネルに従って通知を送信します。

## ログ保持

- **パネルログ保持期間**：監査ログとアクセスログの保持日数（デフォルト 7 日）。期限切れ後は自動クリーンアップ
- アラートイベントの保持日数は別途設定できます（デフォルト 30 日）

## 設定の保存

パネル設定は key-value 形式で SQLite の `settings` テーブルに保存され、ランタイムで読み取られます。2 種類のセンシティブ項目はサーバー側で保護されます：

- **読み取り専用のセンシティブ項目**（`jwt_secret`、`metrics_pass`）：インターフェースがフロントエンドに返しません
- **書き込み保護項目**（`jwt_secret`）：クライアントは上書きできず、サーバー側が自動生成・管理します
