# 대시보드와 모니터링

OpsMini는 지표 수집과 모니터링 알림 기능을 내장하고 있어 별도의 모니터링 컴포넌트 설치가 필요 없습니다.

## 대시보드

로그인 후 기본적으로 대시보드로 진입하며 다음을 표시합니다:

- **리소스 개요**: CPU 사용률, 메모리 점유, 부하, 디스크, 네트워크 트래픽
- **실시간 시계열**: CPU / 메모리 / 디스크 / 네트워크의 시간에 따른 변화 곡선（ECharts 렌더링）
- **시스템 상태**: 실행 시간, 호스트 정보

지표 수집기는 10초마다 샘플링하며, 메모리 링 버퍼는 24시간 보관하고, 이력 데이터는 다운샘플링 후 SQLite에 저장됩니다（1분 단위 7일 보관）.

## 모니터링

모니터링 페이지가 제공하는 것:

- **시계열 조회**: 시간 범위별 이력 지표 조회
- **알림 규칙**: CPU / 메모리 / 디스크 / 서비스 등 지표의 알림 임계값과 지속 시간 사용자 지정
- **알림 이벤트**: 트리거된 알림 이벤트와 상태 조회

### 알림 규칙 예시

| 필드 | 설명 |
|------|------|
| 이름 | 규칙명, 예: 「CPU 지속 과부하」 |
| 지표 | `cpu` / `mem` / `disk` / `service` |
| 조건 | 예: `>90%` |
| 지속 시간 | 트리거 전에 조건을 지속 충족해야 하는 시간 |
| 알림 방식 | 연결된 알림 채널 |

## 알림

알림이 트리거되면 알림 센터를 통해 관리자에게 푸시할 수 있으며, 사이트 내 알림과 읽음 관리를 지원합니다.

## Prometheus 통합

패널은 node_exporter 호환 `/metrics` 엔드포인트를 내장하고 있어 Prometheus가 직접 scrape할 수 있습니다. 자세한 내용은 [Prometheus 지표](../api/prometheus.md)를 참조하세요.
