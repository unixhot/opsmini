# AI 助手

OpsMini 内置 AI 大模型运维能力，用自然语言完成系统诊断、日志分析与命令执行。

## 能力

- **自然语言诊断**：描述故障现象，AI 结合实时系统状态给出诊断建议
- **日志分析**：让 AI 分析异常日志、定位错误根因
- **命令执行**：AI 将自然语言意图转化为运维命令，经权限确认后执行
- **深度思考**：可选「先思考后回答」模式，解决复杂推理问题
- **内置工具**：实时注入主机系统信息（CPU/内存/磁盘/进程/端口/防火墙），并支持通过函数调用在 SkillHub 检索与安装技能

## 支持的 LLM 服务商

| Provider | 说明 |
|----------|------|
| `openai` | OpenAI 兼容接口 |
| `deepseek` | DeepSeek |
| `qwen` | 通义千问（DashScope 兼容接口） |
| `ollama` | 本地 Ollama 部署 |

## 配置

统一在**面板「设置 → AI 大模型接入」**中配置（原 `config.yaml` 的 `ai` 段已迁移到此，运行时即时生效）：

- 启用 AI 助手（总开关）
- 模型服务商 / 模型名 / API Key / API 地址
- 自然语言执行操作 / 日志智能分析 / 告警智能诊断 开关

> 配置优先级：环境变量 `OPSMINI_AI_KEY` > 面板设置 > 配置文件残留的 `ai.*`。建议用环境变量存密钥，避免落盘。详见 [面板设置](../configuration/panel-settings.md#ai-config)。

## 安全机制

- AI 判定为「执行意图」时，生成结构化 action + 参数
- 命中权限白名单才执行；未授权 / 高危操作要求用户二次确认
- 执行动作记录审计日志
- 关闭「启用 AI 助手」开关后，AI 相关接口直接拒绝

## MCP 管理

支持配置 MCP（Model Context Protocol）服务，扩展 AI 助手的能力与数据源。可在「AI 助手 → MCP」中增删改查 MCP 配置，支持命令（stdio）与 URL（SSE/HTTP）两种传输方式。

## 技能（Skill Hub）

内置「技能」标签页，对接 SkillHub 技能市场：

- 检索、一键安装技能
- 上传本地技能、手动创建技能
- 启用/禁用、删除已安装技能
